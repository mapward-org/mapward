# Реализация «доработки-лейаута»

Пользовался: `run_directive { stage: "Реализация" }`, `read_index { file, tail }`,
`finish_directive`. Карту объекта не читал — работа шла по плану, а код клиента карта не
указывает.

- Форматирование `_index.json` карты: `oxfmt` игнорирует `ru/**` (`.oxfmtrc.json`), и по пути
  файлы он не форматирует («All matched files may have been excluded»). Работает
  `oxfmt --stdin-filepath=x.json < файл`. Сначала по ошибке прогнал prettier — стиль другой,
  дифф раздулся. Записал в память.
- Раскладки всех объектов снимал и переписывал скриптом по `_index.json`: MCP раскладку
  вкладок не отдаёт, а писать через него ничего нельзя по замыслу.
- Что нужно было бы: у `read_object` признак «раскладка задана словарём / одиночная» и список
  ключей вариантов — для проверки миграции без чтения файлов.

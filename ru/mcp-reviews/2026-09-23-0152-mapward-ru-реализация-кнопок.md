# Реализация: кнопки в директиве (mapward://)

**Чем пользовался.** `run_directive` и `read_index { file }`: директива в 28 КБ пришла целиком,
по `bytes` было видно, что `tail` не нужен, потому что сжимать надо весь тред ниже строки
«Сжато до коммита». Карта объекта для этой задачи почти не понадобилась: план уже ссылался на
модули относительными путями, и в код я шёл по ним.

**Что не получилось.** Главную развилку, переживает ли переименованная вкладка терминала
перезагрузку окна, через MCP не проверить. Это поведение редактора, а не карты, и отложено на
Тестирование.

**Как было бы удобнее.** Ссылки в плане ведут в папки, и по ним приходилось открывать файлы
вслепую. Будь у метрики `code` объекта `vscode-application` путь до фичи `terminals` с файлами,
я бы начал с неё, а не с `find`. Сейчас, судя по плану, это делается ссылками руками.

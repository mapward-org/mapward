# План: «при запуске директивы имени нет»

Чем пользовался: `run_directive`, `read_index { file, tail: 6 }` — хватило, чтобы увидеть последний
ответ под репликой, без чтения директивы целиком.

Что не получилось: модули для плана (фича терминалов, сборка кнопки этапа) брал поиском по
`apps/vscode-extension/src`, а не из метрик — директива заведена на корне, и её связи с объектом
расширения карта не знает.

Как было бы удобнее: директиве про расширение место на объекте расширения, тогда модули для плана
пришли бы метрикой.

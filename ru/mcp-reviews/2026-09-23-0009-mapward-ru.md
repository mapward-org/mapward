# Тестирование «флоу-установки» на mapward://

**Чем пользовался.** `read_docs` (mcp, directives), `run_directive`, `read_index { file }` —
текст директивы со статусом, `read_object` обзором по корню и
`{ group: "публикация", refresh: "on-display" }` по расширению. Вкладки, экшон `release.md` и три
метрики публикации пришли одним вызовом — сверять обещанное с видимым этим удобно.

**Что не получилось.** Главное обещание директивы — «расширение стоит в моём редакторе и
работает» — MCP не проверяет: метрика `release-vsix` смотрит `code --list-extensions`, то есть
установку, а не активацию. Проверял руками: `grep require` по установленному `extension.cjs` и
`exthost.log`. Значение `release-run` устарело (21.09, пакет 0.25 МБ, до поправки бандла) — по
нему не видно, что последний пакет собирался мимо кнопки.

**Как было бы удобнее.** Пункт в `release-vsix` «последняя активация: ок / упала с …» из
`exthost.log` — тогда этап тестирования этой директивы закрывался бы одним вызовом.

# Отзыв: css компонента перебивает классы карты — этап «Тестирование»

Прошлые этапы шли в другой сессии, этот отзыв — только про Тестирование.

**Помогло:**

- `read_index { file }` отдал статус, этап и тред директивы одним вызовом: обзорный `read_object` ради статуса не понадобился.
- `run_directive` отдал `build` со `stale: false` и временем сборки. По нему сразу видно, что установленное расширение новее реализации, а значит, «не сделанное» из треда (копия плагина списков в карте) уже можно доделать.
- `check_plugin` по `_plugins/views` за один вызов показал, что поправленная копия собирается и все метрики на ней живы. Без него пришлось бы открывать карту и смотреть глазами.

**Потратил лишнее:**

- Ответ `check_plugin` огромный, больше сотни шагов «компонент собран». Хватило бы сводки: сборка, рукопожатие, N метрик ok, а построчно — только упавшие.
- Отличие копии встроенного плагина от registry MCP не показывает, пришлось делать `diff -r` по диску. Подошла бы метрика или поле у плагина: «копия отстаёт от встроенного в таких-то файлах».

**Не проверено через MCP:** меню строки в живой карте. Скриншотом его не снять, оно открывается по наведению или правому клику, а тест в Chromium проверяет саму границу, а не меню.

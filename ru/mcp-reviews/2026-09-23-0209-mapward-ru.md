# Брейншторм «лаконичные ссылки на табы», mapward://

## Чем пользовался

- `read_docs { section: "mcp" }`, `run_directive`, `read_index { file }` — текст директивы и
  `status` пришли одним вызовом, обзорный `read_object` не понадобился.
- Код искал `Grep` по `openInTab|onOpenTab` в `packages/abstract-react-client` — задача про UI,
  и ни одна метрика корня не отвечает на вопрос «где в клиенте живёт такая-то фича».
- Решение `0026` читал с диска: в нём сказано «иконка обязательна», а директива это переворачивает.

## Что не получилось / было бы удобнее

- Директива ссылается на поведение, закреплённое решением, но связи «директива ↔ решение» карта
  не даёт: какие решения задевает правка, приходится находить поиском по коду (в комментариях
  стоит «решение 0026»). Метрика «решения, на которые ссылается код фичи» сократила бы шаг.
- Формат реплики треда (`> [AI]`) в тексте этапа описан, но пример пришлось смотреть в чужой
  директиве. Короткий образец в промпте этапа сэкономил бы вызов.

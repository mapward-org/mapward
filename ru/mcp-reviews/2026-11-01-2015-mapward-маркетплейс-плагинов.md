# Отзыв: mapward:// — маркетплейс плагинов

Все этапы: Брейншторм (13 кругов), План, Реализация, Тестирование.

**Помогло**

- `edit_map` с `check` — одна операция проверяет объект целиком: метрики, раскладку, пробные
  запросы агента. На ней же держится бот реестра: кусок карты проверяется без отдельного харнесса.
- `mapward mcp` по stdio из собранного CLI: на нём проверялись `market_*` до того, как расширение
  в редакторе пересобрали.
- `MAPWARD_MARKET` в папку на диске: весь путь «найти → поставить → сравнить» прогоняется без
  GitHub.

**Где потратил лишнее**

- Список инструментов MCP в сессии Claude фиксируется на старте. Расширение пересобрали, у сервера
  уже есть `market_*`, а у агента их нет до новой сессии. Проверял по `tools/list` руками.
- Номер пачки `undo_edit` живёт в памяти той платформы, которая её сделала. Из отдельного
  `mapward mcp` или CLI кусок карты откатить нечем, только через git. Агент узнаёт об этом по отказу.
- `market add` в CLI отдаёт в `created` только верхние объекты куска. Бот реестра поэтому сначала
  проверял лишь их. Вложенные пришлось искать обходом папок.

**Что сделало бы дешевле**

- `created` у установки куска — все объекты, включая вложенные, или `check` объекта с `recursive`.
- В ответе `market_add` — подсказка, что номер пачки действует только в этом сервере.

# Реализация «стек навигации по объектам»

**Чем пользовался.** `run_directive` — текст этапа. Состав решений и требований смотрел `ls`/`grep`
по `ru/docs` и `ru/requirements`, код — по путям, которые знал с Плана. Проверки гонял с корня:
vitest, `pnpm typecheck`, lint, format:check, build.

**Что не получилось.** Между Планом и Реализацией `entry/app.tsx` изменила параллельная
директива про уведомления (добавила `DirectiveTurns`, уже в коммите). План опирался на старый
текст, поэтому первая правка скриптом упала на несовпадении, и файл пришлось перечитать. Карта про параллельные правки того же
файла ничего не говорит.

**Как было бы удобнее.** Метрика на объекте пакета «файлы, которые трогают незакрытые директивы»
(по путям из их планов) заранее показала бы пересечение.

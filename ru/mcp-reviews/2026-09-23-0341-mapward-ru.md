# Отзыв: Сжатие по 2026-09-22-2315-кнопки-в-дерективе.md, mapward://

Чем пользовался: `run_directive`, `finish_directive`. Директиву дочитал файлом с диска: её всё равно
надо было переписать целиком, а в контексте уже была вся её история.

Что не получилось: коммит перед сжатием упал — файл директивы был неотслеживаемым, и
`git commit -- <путь>` его не знает. Нужен был `git add` перед ним. Записал в память.

Как было бы удобнее: если бы `read_index { file }` отдавал, отслеживается ли файл в git и есть ли в
нём незакоммиченные правки. Промпт Сжатия начинается с коммита, и это первое, что нужно знать.

# Отзыв: брейншторм «нотификации по этапам», где живёт список, mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 10 }`. Чтобы понять, как вебвью
получает живые данные, читал `bridge-handler.ts`: подписка идёт через Observable (`watchMap`),
значит список «ждут ответа» ляжет туда же.

Что не получилось: ничего.

Как было бы удобнее: для архитектурного вопроса нужен был перечень вызовов моста между
вебвью и хостом. Метрика «контракт моста» на объекте core (ключи `appBridge` с типами)
ответила бы без чтения обработчика.

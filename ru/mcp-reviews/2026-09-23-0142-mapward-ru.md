# Реализация по «доработки-лейаута», полоса прокрутки

**Чем пользовался:** `run_directive`, текст директивы пришёл изменением файла в сессии, поэтому
`read_index { file }` не звал повторно. Обзор объекта не нужен: правка в стилях вебвью, которые
карта не описывает.

**Что не получилось:** причину чёрной дорожки и стрелок карта подсказать не могла — она в
стилях по умолчанию самого VS Code (`webview/browser/pre/index.html` в установке редактора).
Нашёл grep по установке.

**Как было бы удобнее:** у объекта `apps/vscode-extension` метрика «стили вида» — где общий css
вебвью и что поверх него кладёт хост — сэкономила бы поиск в этой и прошлой сессии.

# Брейншторм: сохранять состояние карты при сворачивании (mapward://)

Чем пользовался: `read_docs` (mcp, directives), `run_directive`, `read_index { file }`,
`list_maps`. Директива короткая (1 КБ) — `tail` не понадобился, `status: new` пришёл вместе
с текстом, обзорный `read_object` ради статуса не звал.

Что не получилось: карта не ведёт к коду вебвью — аккордеон карт (`packages/abstract-react-client/src/features/maps/ui/accordion.tsx`)
нашёл grep-ом по `collapsed|open=`. Метрики `files` у объектов пакетов, наверное, привели бы туда же,
но для вопроса «где рисуется выбор карт» точнее оказался поиск.

Что было бы удобнее: `list_maps` мог бы отдавать, из какого окна/конфига поднят сервер и какой
у него порт — тогда баг «агент видит чужую карту», описанный в самой директиве, диагностировался бы
одним вызовом, а не догадкой по `mapward.json`.

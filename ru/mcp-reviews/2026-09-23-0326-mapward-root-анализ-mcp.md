# Брейншторм, круг 1 — анализ-mcp, mapward://

## Чем пользовался

- `read_docs { section: "mcp" }` и `{ section: "directives" }`.
- Обзор `read_object { depth: 2, metrics: [], fields: [...] }` отдал сводку директив и этот
  прогон как идущий (`runs: { Брейншторм: 1 }`).
- `run_directive`, затем `read_index { file }`: текст директивы 403 байта, `status: new`.

## Что мешало

- Материал директивы — 181 отзыв на 809 КБ в `ru/mcp-reviews/`, и через карту к нему не
  подойти: ни объекта, ни метрики у отзывов нет. Читал их четыре субагента с диска порциями
  по ~45 файлов, счёт по кластерам складывал руками.
- Раздел «Из отзывов об MCP — отложенное» в `docs/ideas.md` тоже нашёлся только поиском по
  файлу. «Идеи» у карты не адресуются.

## Как было бы удобнее

- Метрика по `mcp-reviews` на корне: кластеры просьб со счётчиком и файлами. Эту же метрику
  уже просил отзыв 0337. Анализ вроде этого сводился бы к одному `read_object`.

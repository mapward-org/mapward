# Тестирование «лаконичные ссылки на табы», mapward://

## Чем пользовался

- `read_index { file, tail }`, `run_directive { stage: "Тестирование" }`, `finish_directive`.
- С планом сверял grep по коду клиента: `TabIcon` остался только в шапке объекта и у заголовка
  метрики, отступов под иконку и фразы «иконка обязательна» в коде нет. Проверки typecheck,
  lint, test и format:check прошли.

## Что не получилось / было бы удобнее

- То, что обещала директива, — подсветка под ctrl в вебвью. Через MCP это не видно: там данные,
  а не отрисовка. Пункт этапа «посмотри карту через MCP» для UI-директив проверять нечем.
- В `ru/mcp-reviews` лежат десятки незакоммиченных отзывов параллельных сессий. Чтобы
  закоммитить только свои, пришлось сверять заголовки. Если бы в имя отзыва входило имя
  директивы, свои файлы находились бы по маске.

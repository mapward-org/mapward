# Брейншторм «кнопки-экшоны», круг 4 — mapward://

Чем пользовался: `read_docs` (mcp, directives, оглавление, metrics), `run_directive`, обзорный
`read_object` по рецепту, `read_index { file }` для текста директивы.

Что было удобно: `runs` в сводке директив сразу сказал, что это четвёртый круг, — не пришлось
выяснять по треду. `read_index { file }` отдал текст целиком, при 6,6 КБ `tail` не нужен.

Чего не хватило: по ответу `read_index` не видно, кончается ли файл переводом строки, — а
реплика `>>` к ответу без него приклеивается. Пришлось смотреть `tail -c | od -c`. Было бы
удобно поле вроде `trailingNewline: false` или просто `endsWithNewline` рядом с `bytes`.

Обзор с `depth: 2` на корне по-прежнему в основном про связи и `shared-metrics` — для
директивы корня хватило бы `depth: 0`; рецепт этого не различает.

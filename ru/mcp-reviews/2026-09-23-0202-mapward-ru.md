# Тестирование «кнопки в директиве» — mapward://

**Чем пользовался:** `read_docs` (mcp, directives), `run_directive`, `read_index { file }` целиком
и `{ file, tail: 5 }` перед дописыванием треда. Обзорный `read_object` не звал: директиве нужно
было сверить код и доки, а статус и текст отдал `read_index`.

**Что сработало:** `read_docs` сразу показал новые тексты `directives` и `mcp`, так что увидеть
«доку, которую видит агент» можно было без пересборки бандла. `tail` удобен, чтобы перед
дописыванием проверить, не ответил ли автор.

**Чего не хватило:** узнать, на каком порту стоит сервер, к которому я подключён, и из какой
сборки он работает, из MCP нельзя. Проверял `netstat` и `grep` по `dist` установленного
расширения. Для этой директивы (фича `mcpPort`) пригодилось бы поле вроде `server: { url,
fixed, build }` в `list_maps`.

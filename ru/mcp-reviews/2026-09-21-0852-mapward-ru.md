# Отзыв о работе с картой — 2026-09-21 08:52, объект «Mapward (ru)»

Этап «Тестирование» по директиве `2026-09-21-0214-разделение-метрик-по-группам.md`. Прошлый
прогон этого же этапа проверку доделал, но `finish_directive` поставить не смог — сервер лёг.
То есть эта сессия — почти целиком перепроверка чужой работы по карте, без правок.

## Чем пользовался

- `read_docs { section: "mcp" }`, `read_docs { section: "directives" }`.
- `read_object` обзорным вызовом с `depth: 2, metrics: [], fields: [...]` — дал всю структуру
  и сводку директив одним ответом, к репозиторию идти не пришлось.
- `read_object { fields: ["groups", "metrics.key", "layout", "workflow.name"] }` — лучший
  вызов этой сессии. Сразу видно: девятнадцать метрик, `layout` пустой, вкладок четыре,
  и союз ключей по вкладкам совпадает с перечнем метрик. Три обещания директивы закрыты
  одним ответом.
- `read_object { group, refresh: "on-display", fields: ["metrics.key", "metrics.value.ok",
  "metrics.value.collected", "metrics.value.updatedAt"] }` по каждой вкладке — здоровье
  всех метрик без единого значения в ответе. Три таких вызова параллельно уложились в
  один ход и в пару килобайт.
- `read_object { metrics: [...], fields: ["metrics.value.data"] }` — точечно за значениями
  четырёх новых метрик.
- `read_index` по корню (сырой `_index.json` с раскладками вкладок — их мердж не отдаёт) и
  `read_index { file }` за текстом директивы.
- `run_directive` / `finish_directive`.

## Что сработало хорошо

- **Проекция на `metrics.value.ok` работает вглубь значения.** В доке показаны пути уровня
  `metrics.value`, и что можно спуститься ниже — в `metrics.value.collected` — я проверял
  наугад. Работает, и это ровно тот вызов, которым проверяют «собралось ли всё»: девятнадцать
  метрик здоровьем на два килобайта вместо ста. Стоит показать этот путь в разделе `mcp`
  рядом с примером про `metrics.config` — сейчас за ним не идут.
- `refresh: "on-display"` по вкладке — честная проверка «то же, что человек на экране»:
  `manual`-метрики (`architecture-quality`, `decisions-drift`) остались с кэшем, остальные
  семнадцать пересчитались за секунду.
- `layout: {}` в ответе — именно то, что нужно было увидеть: раскладка объекта убрана, состав
  задают вкладки. Пустой объект тут читается однозначно.

## Что не получилось

- **Раскладку вкладки MCP по-прежнему не отдаёт.** В `groups` приходят четыре поля
  (`key`, `label`, `description`, `metrics`), а `details-metrics-layout` вкладки — нет. Главный
  инвариант `0029` («рядов в `gridTemplateRows` столько же, сколько строк в `areas`») я
  проверял по сырому `_index.json` из `read_index`, то есть мимо мерджа: у наследника вкладка
  может прийти от прототипа, и тогда этой проверки через карту не сделать вовсе. Наблюдение
  в памяти про это уже лежит — подтверждаю второй сессией подряд.
- **Значения `metrics.value` не отличить «моё / от прототипа» без второго вызова.** Мелочь,
  но при проверке «метрика заведена на корне, а не досталась» приходится звать `metrics.owner`
  отдельным полем; в одном ответе с `value` это перебор по весу. Ничего не сломано, просто
  проверка состава метрик всегда двухходовая.
- **`directive-runs` показала идущий прогон как «не закрыт»** — это правда, но в момент, когда
  ты сам этот прогон и открыл, строка выглядит как находка. Не баг карты, а свойство метрики
  про саму себя; на будущее: собственный идущий этап стоило бы помечать отдельно.

## Как было бы удобнее для этой задачи

Задача была «проверить, что чужая реализация легла». Ей не хватило одного:

- **Сверки `areas` с составом вкладки на стороне карты.** Оба фильтра (`0025` и `0029`)
  перемножаются, и расхождение между ними — самая дорогая ошибка в этой директиве: метрика
  молча исчезает с экрана. Сейчас это проверяется глазами по json. Напрашивается либо
  `groups[].details-metrics-layout` в ответе `read_object`, либо готовый ответ карты «метрики,
  названные в группе, но не попавшие в `areas`» — второе даже полезнее, потому что это ровно
  формулировка инварианта.

Прогоны проверок (`lint`, `format:check`, `typecheck`, `test`) шли мимо карты, как и положено:
это не метрики, а команды. Заняли около трёх минут, все зелёные.

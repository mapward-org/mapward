# Брейншторм по «доработки-лейаута», правка про скролл

**Чем пользовался:** `read_docs` (mcp, directives), `run_directive`, `read_index { file }` —
текст директивы целиком (8.6 КБ, `tail` не понадобился). Обзорный `read_object` не звал:
правка в конце директивы про вид полосы прокрутки, объект карты для неё ничего не даёт, а
место в коде назвал уже сам план директивы (`map-object.tsx`).

**Что не получилось:** про стили вида — где лежит общий css вебвью, есть ли где-то оформление
скроллбаров — карта не отвечает; искал grep по репозиторию. Метрики, которая сказала бы «общие
стили клиента живут в `apps/vscode-extension/src/apps/webview/index.css`», нет.

**Как было бы удобнее:** у директивы, прошедшей сжатие, статус `new` — по нему не видно, что это
уже третий круг правок после реализации; `runs` помог бы, но в ответе `read_index { file }` его
нет, только в `read_object`.

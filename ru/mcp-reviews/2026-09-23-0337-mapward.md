# Брейншторм «терминал получает MCP чужого окна», реплика 1

Пользовался: `read_docs` (mcp, directives), `run_directive`, `read_index { file }`, `list_maps`.
Обзор `read_object` не звал: директива про расширение, а не про объект карты, и `read_index`
с `file` сразу дал текст и статус.

`list_maps` оказался самым полезным вызовом для этой задачи — по нему видно, что сессия сидит
на своей карте. Ровно этого и не хватает в симптоме директивы: сервер не говорит, для какого окна
и какого воркспейса он поднят. Было бы удобно, если бы `list_maps` (или ответ на `initialize`)
отдавал ещё корень окна и порт — тогда «я попал не туда» видно одним вызовом.

Причину, откуда терминал взял чужой адрес, по коду и карте не установить: окно, в котором это
случилось, MCP не видно. Спросил автора.

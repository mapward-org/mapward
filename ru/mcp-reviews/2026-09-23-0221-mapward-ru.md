# Отзыв: Брейншторм по 2026-09-22-2315-кнопки-в-дерективе.md, mapward://

Чем пользовался: `read_docs` (разделы mcp и directives), обзорный `read_object` с `fields`,
`run_directive`, `read_index { file }` — по этой директиве и по соседней «кнопки-экшоны».

Что получилось: директива маленькая, и `read_index { file }` сразу отдал текст со статусом, так что
файлом с диска читать не пришлось. То, как кнопки этапов устроены сейчас, есть в разделе directives —
ради этого не пришлось лезть в код, код нужен был только чтобы найти `runStage`.

Что неудобно:
- Чтобы дописать реплику в тред, файл всё равно читается и правится с диска. `read_index` не даёт
  гарантии, что автор не дописал его за секунду до правки. Пригодилась бы проверка «файл не менялся
  с такого-то `bytes`/хэша», например хэш в ответе `read_index`.
- Отзывы именуются по минуте, а часы оболочки (`date`) не совпадают с тем, как названы файлы
  в `mcp-reviews`. Свободную минуту пришлось подбирать по списку. Удобнее, если бы имя отзыва
  выдавал `run_directive` или `finish_directive`.

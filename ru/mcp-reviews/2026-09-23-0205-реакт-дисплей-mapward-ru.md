# Брейншторм «реакт-компонент-дисплей», mapward://

Чем пользовался: `read_docs` (mcp, directives, config), `run_directive`, `read_index { file }`,
`finish_directive`. Обзорный `read_object` не звал: вопрос был про резолв пакетов, а статус и
текст директивы пришли из `read_index { file }` — этого хватило.

Что не получилось: настройки `mapward.json` конкретной карты через MCP не видны — `read_docs`
описывает поля, а какие из них выставлены здесь (есть ли `baseUrl`), пришлось смотреть `cat`.

Как было бы удобнее: `list_maps` мог бы отдавать эффективный конфиг карты — `mapUrl`, `baseUrl`
абсолютными путями и рантайм-настройки. Вопросы «где корень проекта этой карты» в директивах про
сборку и резолв встают часто.

Имя `2026-09-23-0205-mapward-ru.md` уже было занято параллельной сессией — взял имя с темой.

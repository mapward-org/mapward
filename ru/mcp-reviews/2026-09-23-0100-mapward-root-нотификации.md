# Отзыв: брейншторм «нотификации по этапам», mapward://

Чем пользовался: `read_docs` (mcp, directives), `run_directive`, `read_index { file }` — текст
директивы со статусом одним вызовом, обзор `read_object` не понадобился: тред короткий (5 КБ),
весь контекст был в самой директиве. В код сходил одним grep по расширению — нашёл
`stage-tabs.ts`, где обёртка вокруг `finishDirective` уже есть и прямо помечена как место для
уведомлений.

Что не получилось: ничего не сломалось.

Как было бы удобнее: дописывать реплику треда приходится мимо карты, `cat >>` в файл. Для
брейншторма, где каждый прогон — ровно одна реплика в конец, хватило бы, чтобы
`finish_directive` принимал текст реплики и дописывал его сам — тогда и гонка с автором,
который пишет в тот же файл, решалась бы на стороне карты.

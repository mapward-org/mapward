# Брейншторм «стек навигации по объектам», прогон 4

**Чем пользовался.** `read_docs` (mcp, directives), `run_directive`, `read_index { file }`,
`read_object { metrics: [], fields: ["directives"], directives: "all" }` — ради `runs` и `run`.

**Что вышло.** Прогон пустой: на последнюю реплику `> [AI]` автор не ответил, а следующую
реплику без ответа писать нельзя — тред одна тема за раз. Файл директивы не трогал.

**Что не получилось / было бы удобнее.**

- Прошлый прогон (начат 2026-09-22 23:18) не закрыт `finish_directive` — `run` без
  `finishedAt`. Карта это знает, но `run_directive` об этом молчит: удобно было бы получить в
  ответе «предыдущий прогон этого этапа не закрыт» и «после последней реплики `[AI]` ответа
  автора нет» — второе видно только глазами по тексту.
- Что рабочая копия директивы переписана относительно коммита (71 строка вопросов свёрнута в
  одну реплику), видно только через `git diff` — MCP про git-состояние файла директивы не говорит.
- `read_index { file }` удобен: статус и текст одним вызовом, обзор ради статуса не понадобился.

# Брейншторм «доработки-лейаута» на mapward://, первая реплика

**Чем пользовался.** `run_directive`, `read_index { file }` — текст директивы. `read_docs` уже
был прочитан в этой сессии.

**Что не получилось.** Вопрос директивы — «какие высоты рядов карта пишет сейчас» — через MCP
не задать: `groups` отдаётся без `details-metrics-layout`, раскладка объекта не приходит
(это уже в памяти). Собирал `grep` по `_index.json` карты. Код сетки и клетки нашёл по памяти о
путях, а не по метрике — у корня метрики «где лежит код раскладки» нет.

**Как было бы удобнее.** Поле `layout` в `read_object` у каждой вкладки целиком — `areas` и
`style`, — хотя бы по явному `fields: ["groups.details-metrics-layout"]`.

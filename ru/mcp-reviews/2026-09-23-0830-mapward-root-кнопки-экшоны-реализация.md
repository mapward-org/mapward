# Реализация «кнопки-экшоны» — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail }`. Дальше почти всё шло мимо карты:
реализация трогала `core`, сервер, клиент, CLI и расширение, и искать нужные модули приходилось
`grep`-ом — карта называет пакеты, но не их фичи и не то, где реализован порт.

Не хватило:
- метрики «фичи пакета» с одной строкой на папку — для сервера и клиента это сэкономило бы
  десяток `ls`;
- поиска по доке (`read_docs { query }`) — чтобы найти все разделы, где упомянут экшон, пришлось
  `grep`-ать `packages/docs/ru`;
- пакет `packages/display` не заведён объектом карты, в обзоре его нет.

Удобно было: сжатая директива в четыре раздела — по ней и план, и отчёт собираются без
перечитывания треда.

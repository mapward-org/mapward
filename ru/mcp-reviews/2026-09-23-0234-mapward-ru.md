# Отзыв: Брейншторм по 2026-09-22-2315-кнопки-в-дерективе.md, mapward://, третий круг

Чем пользовался: `run_directive`, `finish_directive`. Ответ автора пришёл уведомлением об изменении файла.

Что заметил: привязка «директива → терминал, где её запускали последним» знает только о запусках
кнопкой. Сам этот тред запускается словами, и такой прогон расширение не видит: `run_directive`
приходит в MCP, но из какого терминала — неизвестно. Чтобы привязка работала и для запуска словами,
MCP-соединению нужен признак сессии. Например, id терминала в адресе сервера из `--mcp-config`,
который ставит расширение. Сейчас из карты этого не узнать, нашёл только по коду.

Как было бы удобнее: если бы `run_directive` возвращал или хотя бы записывал в состояние прогона,
из какой сессии он пришёл.

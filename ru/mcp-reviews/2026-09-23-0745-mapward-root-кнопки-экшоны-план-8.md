# План «кнопки-экшоны», кусок 8 — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 6 }`. Тексты экшонов читал с диска
`head`-ом, а не `read_index { file }`: нужны были первые строки шести файлов сразу, а по
одному вызову на файл это шесть вызовов. Кто ссылается на экшоны, считал `grep` по `ru/map`.

Было бы удобно: `read_index` с `files: [...]` и `head`, как `tail` — первые строки нескольких
экшонов одним вызовом.

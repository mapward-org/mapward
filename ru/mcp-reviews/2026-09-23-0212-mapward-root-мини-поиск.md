# Реализация «мини-поиск-по-директивам», mapward://

## Чем пользовался

- `read_docs { section: "mcp" }`, `run_directive`, `read_index { file }` — текст директивы
  пришёл сразу со `status: new` и `bytes`, по ним понял, что треда нет и сжимать нечего.
- Обзорный `read_object` не звал: задача — правка UI клиента, а карта отвечает про объекты
  и метрики, не про то, какой компонент рисует мета-экран.

## Что не получилось

- Дорогу к коду карта не дала: у корня нет метрики, которая сказала бы «вебвью мета-экрана
  лежит в `packages/abstract-react-client/.../_meta`». Нашёл обычным поиском по слову
  «директив» в `.ts`/`.tsx` — за два запроса, но мимо карты.

## Как было бы удобнее

- Для UI-директив пригодилась бы метрика у `abstract-react-client` (или у корня) вида «экраны
  клиента → файлы»: мета-экран, сетка, шапка, список директив. Тогда «в информации об
  объекте» переводилось бы в путь одним `read_object`.

# Брейншторм «кнопки-экшоны», круг 6 — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 14 }`. Больше ничего не понадобилось:
документация, обзор и памятка были в контексте с прошлых кругов этой сессии.

Удобно: `tail` с небольшим запасом отдаёт последнюю реплику вместе с ответом автора. Зная длину
своей реплики, число строк можно выбрать заранее.

Не хватило: всё то же — не видно, есть ли перевод строки в конце файла. Автор отвечает без
него каждый раз, поэтому перед каждой репликой приходится проверять `od -c`.

# Брейншторм · 2026-09-21-0246-улучшение-промптов · mapward://

## Чем пользовался

- `run_directive` — промпт этапа.
- `read_index { file }` — текст директивы вместе со статусом и `bytes`.
- `read_index { stage }` пять раз — тексты остальных этапов, без запуска прогонов. Для
  директивы про сам воркфлоу это главное, и сработало ровно как нужно.

## Что не получилось

- Воркфлоу целиком одним вызовом не достать: `read_object` отдаёт `workflow` списком этапов, а
  тексты — только по одному через `stage`. Для директивы, которая переделывает все этапы сразу,
  это пять вызовов подряд.
- Какие решения касаются воркфлоу, MCP не подскажет: нашёл `grep` по `ru/docs/decisions`
  (0017, 0020). Метрика решений на корне есть, но поиска по теме у неё нет.
- `bytes` директивы в обзоре (7850) не совпал с тем, что отдал `read_index` (3264): автор
  переписал файл между вызовами. Сверять ничего не пришлось, но расхождение сбивает с толку.

## Как было бы удобнее

- `read_index { stage: "*" }` или `read_object { fields: ["workflow.text"] }` — все тексты
  этапов одним ответом.

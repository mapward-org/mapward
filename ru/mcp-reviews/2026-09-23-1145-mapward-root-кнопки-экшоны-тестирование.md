# Тестирование «кнопки-экшоны» — mapward://

Чем пользовался: `run_directive`, `read_object { fields: ["address", "actions"] }` — экшоны с формой
пришли у корня, живой сервер уже на новой сборке. Прогоны смотрел файлом `.mapward/runs/_root.json`:
у MCP прогоны объекта отдаются только по номеру (`read_run`), списка нет.

Было бы удобно: `read_object` с полем `runs` — последние прогоны объекта, как на экране.

# План «кнопки-экшоны», кусок 5 — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 6 }`. Формы дисплеев сверял по
`core/src/model/display.ts`. `read_docs { metrics }` описывает их прозой, но полей для
подсказки агенту (строка формы в промпте) там нет — они только в коде.

Удобно было бы получить формы дисплеев из `read_docs` той же строкой, что уезжает агенту в
промпт: тогда план по форме данных не требует похода в код.

# Брейншторм «доработки-лейаута» на mapward://, вторая реплика

**Чем пользовался.** `run_directive`; текст директивы на этот раз — с диска, потому что
перед дописыванием реплики файл всё равно перечитывается (автор отвечает в него по ходу).

**Что не получилось.** Автор сослался на «аккордеон» — это компонент клиента, а не объект
карты, и MCP о нём ничего не знает: нашёл `grep` по `packages/abstract-react-client/src`. У
пакета клиента на карте есть метрика кода, но по вопросу «где вёрстка вида объекта» она не
отвечает — только «где пакет».

**Как было бы удобнее.** Для директив про интерфейс — метрика у `abstract-react-client`,
которая раскладывает фичи клиента по экранам: «сайдбар → аккордеон → вид объекта → сетка».

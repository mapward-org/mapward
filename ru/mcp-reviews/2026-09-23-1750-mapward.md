# Брейншторм «файловые-деревья», круг 1

Пользовался: `read_docs mcp`, `run_directive`, `read_index { file }`, обзорный `read_object`.

- Директива про UI вебвью, а не про метрику объекта — карта здесь почти не помогла: код дерева
  (`file-tree.tsx`) и механизм запоминания (`useViewState`) нашёл grep-ом по `packages`.
  Метрики-указателя «где лежит отображение `tree`» у объекта нет.
- Обзор с `depth: 2` вернул директивы всех объектов, хотя нужен был только корень; для этапа
  по одной директиве хватило бы `read_index { file }` — он уже отдаёт статус.
- Удобнее было бы: у пакета `abstract-react-client` метрика «компоненты отображений» — вид
  отображения → файл.

# Этап «Тестирование» по директиве `кнопка-удаления-директивы-нужна`, объект `mapward://`

Директива из трёх строк, без разделов «План» и «Реализация»: предыдущие этапы в файл ничего
не дописали. Проверять пришлось по коду целиком — текст сказал только, чего хотели, и ни слова
о том, что для этого сделали.

## Чем пользовался

- `run_directive` — промпт этапа и отметка о прогоне.
- `read_index { file }` — текст директивы из карты по имени.
- `read_object` с `directives: "all"` и `fields: ["address", "directives"]` по
  `apps/vscode-application` — искал директиву с `owner`, чтобы проверить ветку «у прототипной
  крестика нет» на живой карте. Не нашёл: унаследованных директив на этой карте нет вовсе,
  все девять свои.
- Мимо MCP: `grep` по `deleteDirective` через все слои — контракт, юз-кейс, экспорт, мост,
  адаптер клиента, UI, — и `pnpm test / typecheck / lint / format:check / build` с корня.

## Что не получилось

- **Проверять было нечего в карте, а много — в коде.** Директива обещает кнопку, и всё, что
  она затронула, — это шесть файлов в двух пакетах и расширении. MCP про них не знает ничего:
  `read_object` показывает директиву, её статус и прогоны, но не то, во что она превратилась.
  Этап «Тестирование» на такой директиве идёт целиком грепом.
- **Ветку «не для прототипных» нечем проверить.** Условие в клиенте — `file.owner ===
  undefined`, и `owner` проставляется в `read-map.ts:272`, но ни у одного объекта этой карты
  унаследованной директивы нет. То есть случай, ради которого в директиве стоит отдельная
  оговорка, живой картой не покрывается — остаётся тест на «удалять нечего» и чтение кода.
- **Короткая директива не оставляет следа своих этапов.** Брейншторм, Проверка, План
  и Реализация по ней прогонялись — это видно по состоянию, — а в файле после них пусто.
  Сверять «сделан пункт или нет» не с чем: пунктов нет, есть три строки пожелания.

## Как было бы удобнее

- **Тронутые файлы у прогона.** Сервер знает `startedAt` и `finishedAt`; список путей,
  изменившихся между ними, превратил бы проверку такой директивы из грепа в сверку.
  Прошу второй раз подряд, но здесь это заметнее: текста, по которому можно сверять, нет совсем.
- **Объект-песочница для веток наследования.** Прототипная директива, прототипный экшон —
  того, чего на карте нет, проверить на ней нельзя, а такие ветки есть в каждом втором
  требовании. Фикстура в тестах это закрывает, живая карта — нет, и они расходятся молча.

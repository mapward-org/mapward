# План «реакт-компонент-дисплей», кусок 1, mapward://

Чем пользовался: `run_directive`, обзорный `read_object` (depth 2, без метрик, с `props`) —
из `props.codePath` взял папки пакетов, `finish_directive`.

Что не получилось: до места правки (`schema.ts`, `display.ts`, `shapeHint`) шёл `grep` по
`packages/*/src`. Метрики `files` не звал: они отдают дерево файлов, а вопрос был «где
перечислены виды дисплеев» — это поиск по содержимому, дерево на него не отвечает.

Как было бы удобнее: для плана полезна метрика «точки входа пакета» — ключевые модули со
строкой назначения (как в архитектурной доке), с путями. Тогда кусок плана раскладывается по
модулям сразу из карты, а `grep` остаётся только для строки внутри файла.

# Отзыв: Брейншторм, «сохранять состояние колапсов», mapward://

Пользовался: `read_docs { section: "mcp" }`, `run_directive`, `read_index { file }`. Директива
короткая (250 байт), `tail` не понадобился; статус `new` пришёл прямо из `read_index`, обзорный
`read_object` ради него не звал.

Что не получилось через карту: вопрос «где в клиенте живут сворачивания» — это UI-код пакета
`abstract-react-client`, метрики на него не вели прямо, искал grep-ом по `src`. Для директив про
интерфейс удобно было бы, чтобы у объекта клиента была метрика «где что в UI» (фича → папка).

Решение 0028 (то, с чем директива спорит) нашёл по комментарию в коде, а не через карту: поиск
решений по теме («свёрнутость») в MCP был бы полезен.

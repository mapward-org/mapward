# Брейншторм, круг 2 — анализ-mcp, mapward://

## Чем пользовался

- `run_directive` и `read_index { file, tail: 8 }`: хвоста хватило, чтобы увидеть ответ автора.

## Что мешало

- Ответ автора кончается без перевода строки. `tail` этого не показывает, заметил только по
  тексту. Реплику дописал через Edit, а не `>>`.
- `run_directive` второй раз подряд отдал тот же полный промпт этапа, около 5 КБ.

## Как было бы удобнее

- Поле `endsWithNewline` в ответе `read_index`, а лучше — чтобы реплику дописывала сама карта.

# Брейншторм «реакт-компонент-дисплей», третий круг, mapward://

Чем пользовался: `run_directive`, `finish_directive`. Круг короткий: автор ответил на последний
вопрос, осталось проверить четвёртую фазу и закрыть брейншторм.

Что не получилось: сверка с решением о схеме метрик (0004, раздел про дисплей и форму данных)
шла `sed` по файлу в `ru/docs/decisions`. Через MCP решения не читаются — ни по номеру, ни по
теме, хотя этап прямо требует сверяться с ними.

Как было бы удобнее: `read_docs`-подобный вызов для решений и требований проекта — по номеру
отдать текст, без номера отдать список заголовков. Тогда четвёртая фаза шла бы через карту,
как и остальные.

# Реализация правок «кнопки-экшоны» — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail }`. Экшон проверял `mapward action` из
терминала — это быстрее, чем ждать MCP живого окна, который обслуживает старую сборку.

Не хватило: `read_run` есть только в MCP, а у CLI нет команды посмотреть прогоны объекта —
чтобы убедиться, что прогон записался, пришлось читать `.mapward/runs/*.json` руками.

# Тестирование: стек навигации по объектам

Директива `2026-09-21-1257-стек-навигации-по-объектам.md`, этап «Тестирование».

## Чем пользовался

- `run_directive` — промпт этапа; `read_index { file }` — текст директивы вместе со статусом.
- `read_object` на `packages/abstract-react-client`: перечень ключей через `fields: ["metrics.key"]`,
  потом `metrics: ["requirements", "decisions"]` с `refresh: "on-display"` — новое требование
  и 0036 видны, с git-пометкой `U`.

## Что не получилось

- Первым вызовом снова дал `metrics: []` вместе с `metrics.key` в `fields` — отказ. Текст
  отказа хороший, сразу говорит, как надо; в памяти это тоже записано, а всё равно наступил:
  обзорный рецепт из доки приучает к `metrics: []`.
- Проверить стрелки живьём через карту нельзя: это поведение вебвью, MCP его не видит. Проверка
  — тесты чистой модели и чтение кода.

## Как было бы удобнее

- `decisions` и `requirements` отдают дерево целиком; для проверки директивы хватило бы
  отбора по git-статусу — «что поменялось с последнего коммита», пара строк вместо 15 КБ.

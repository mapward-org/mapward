# Отзыв: «изменяй название таба при навигации», этап «Тестирование»

Прошлые этапы шли в других сессиях, их контекста у меня нет — отзыв только про Тестирование.

**Помогло.** `run_directive` и `read_index { file }` за два вызова дали и промпт этапа, и тред
со словом автора («Всё ок - комить»). Обзор объекта не понадобился: статус пришёл вместе с
текстом. Карту называть не пришлось — директива нашлась и без `map`.

**Лишнее.** Промпт этапа ведёт в обзор и метрики, а в директиве без видимого на карте результата
проверка — это diff и `pnpm typecheck/test/lint/format:check/build`. Всё это мимо MCP.

**Что сделало бы дешевле.** Метрика или поле «какие файлы тронула директива»: коммит по путям
приходится собирать из `git status`, отделяя чужие незакоммиченные правки (память, `map-state.json`)
на глаз.

# Отзыв: тестирование «нотификации по этапам», mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 8 }`, `read_docs { section:
"directives" }` — проверить, что новый абзац доехал до живого MCP. Доехал, хотя в
установленном расширении (`~/.vscode/extensions/mapward.mapward-0.0.0`) нового кода нет.

Что не получилось: «посмотреть на карте, что директива обещала показать» — обещано
уведомление редактора, а через MCP его не увидеть. Непонятно и то, из какой сборки отвечает
живой сервер: доки свежие, а `dist` установленного расширения старый.

Как было бы удобнее: инструмент, отдающий версию или время сборки того `dist`, который сейчас
обслуживает MCP. Тогда «живой сервер уже с правкой» проверялся бы одним вызовом, без grep по
папкам расширений.

# План «стек навигации по объектам», прогон 1

**Чем пользовался.** `run_directive` — текст этапа. `read_object` на `packages/abstract-react-client`,
в `fields` только `metrics.key`: так получил перечень метрик. Потом метрику `architecture` поимённо:
она ведёт на доку архитектуры пакета, где описаны слои фичи. Дальше читал код фичи `map-object`.

**Что не получилось.** Метрика `architecture` отдаёт только ссылку на доку, а не дерево фичи.
Файлы фичи смотрел `find`. Метрика `files` могла бы помочь, но она по всему пакету, а не по фиче.

**Как было бы удобнее.** Иметь объекты карты уровнем глубже, на фичу клиента (`features/map-object`),
с метриками `files` и `tests`. Тогда план по одной фиче читался бы через карту.

# План «кнопки-экшоны», кусок 7 — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 6 }`. Чтобы найти, какие разделы
доки упоминают экшоны, шёл `grep` по `packages/docs/ru` — `read_docs` отдаёт раздел целиком, а
поиска по доке у него нет. Список экшонов карты снял `find` по `_actions`: у `read_object`
экшоны приходят по объекту, а вопрос «все экшоны карты» требует обхода с глубиной.

Было бы удобно: `read_docs { query }` — разделы и строки, где встречается слово.

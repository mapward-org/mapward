# Отзыв: этап «План», директива «сохранять состояние карты при сворачивании», mapward://

**Чем пользовался.** `read_docs` (mcp, directives), `run_directive`, `read_index { file }` —
текст директивы целиком (6 КБ, `tail` не понадобился). Обзорный `read_object` не звал: объект
корневой, а нужный код (фича `maps` клиента) метрикой не адресуется так, чтобы это было быстрее
прямого `ls` по папке, которую уже назвал кусок 1.

**Что не получилось.** Ничего не сломалось. Код искал обычным `grep` по клиенту и расширению:
где хранилище вида (`memento` = `workspaceState`) и кто ещё зовёт `useViewState`.

**Как было бы удобнее.** Для плана по UI-фиче полезна метрика «кто пользуется этим сервисом»
на объекте клиента — вопрос «где ещё зовут `useViewState`» задаётся каждый раз, когда правка
трогает хранимое состояние вида.

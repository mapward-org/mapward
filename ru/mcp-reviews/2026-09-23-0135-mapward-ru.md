# План «доработки-лейаута», кусок 4 и готовность

Пользовался: `read_index { file, tail: 14 }`, `run_directive`, `finish_directive`.

- Сводку раскладок карты (сколько колонок и рядов у каждой, у кого `gridTemplateRows`) снимал
  скриптом `node` по восьми `_index.json`: MCP раскладку вкладок не отдаёт (`groups` обрезан),
  а сырой `read_index` по каждому объекту — восемь вызовов с полными индексами. Проекция вроде
  `fields: ["layout.areas"]` по всему дереву с `depth` закрыла бы это одним вызовом.

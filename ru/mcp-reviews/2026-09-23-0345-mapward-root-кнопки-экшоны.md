# Брейншторм «кнопки-экшоны», круг 5 — mapward://

Чем пользовался: `run_directive`, `read_index { file, tail: 20 }`. Документацию и обзор не
перечитывал — они были в контексте с прошлого круга в той же сессии.

Удобно: `tail` отдал ровно последний круг — мою реплику и ответ автора, — плюс `lines` и `bytes`.
Больше для этого круга ничего не понадобилось.

Не хватило того же, что и в прошлый раз: не видно, кончается ли файл переводом строки. Автор
снова ответил без него, пришлось смотреть `od -c`. Поле `endsWithNewline` в ответе
`read_index { file }` это сняло бы.

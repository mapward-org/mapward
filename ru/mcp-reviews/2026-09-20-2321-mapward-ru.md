# Отзыв о работе с картой

Этап целиком про тексты: найти противоречие директивы действующим решениям и реестру. Ровно
этих текстов карта и не отдаёт — она отдаёт их имена. Поэтому прогон получился на две трети
вне MCP.

## Чем пользовался

- `read_docs { section: "mcp" }`, `{ section: "directives" }`.
- `read_index { file }` на корне — текст директивы с ответами автора. Полезная мелочь: `bytes`
  сразу показал, что автор дописывал в файл между этапами — 451 байт стали 8589. Раньше это
  выяснялось только по содержимому.
- `read_index { file }` на `prototypes/system` — тексты обоих экшонов про требования, за два
  вызова и без выяснения, где они лежат.
- `read_object { fields: ["metrics.key", "metrics.owner"] }` — какие метрики на объекте есть
  и чьи они.
- `run_directive` / `finish_directive`.

## Что мешало именно этому этапу

1. **Решения приходят именами, а проверять надо текст.** Метрика `decisions` отдаёт 21 ссылку;
   чтобы найти одно противоречие — `0010:104-105`, где сказано догонять реестр задним числом, —
   я грепал папку решений и читал два файла целиком. Для этапа, чья единственная работа
   в этом и состоит, это не мелкое неудобство: вся Проверка идёт мимо карты. Седьмая просьба
   за день.

2. **Обратных ссылок нет.** Вопрос «что сломается, если тронуть `0010`» — это вопрос «кто на
   него опирается»: гайд, два экшона, две метрики. Карта такого вопроса не знает, собирал
   грепом. Шестая просьба.

3. **Инвариант решения не виден из карты.** Проверять, не ломает ли директива чей-то инвариант,
   пришлось грепом по `## Инвариант` — и так выяснилось, что у `0010` и `0011` его нет вовсе,
   а есть только у `0014`–`0022`. Это ровно тот срез, который метрика `decisions` могла бы
   отдавать вместе с именами: решение, статус, есть ли инвариант.

4. **Реестр требований — снова счётным вопросом.** «Описывает ли хоть одно требование статусы
   или порядок работы» — грепом по `ru/requirements/`. Метрики отдают дерево для глаз.

## Что понравилось

- Правило «текст экшона бери из карты по имени» впервые не стоило ничего: оба экшона нашлись
  у прототипа, хотя объект — корень, и путь к ним я не склеивал.
- `bytes` у файла директивы работает и как признак «автор дописал»: размер в сводке виден
  до чтения.

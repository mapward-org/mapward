## Обработка воркспейсов

Добавь решение и описание требований. Обнови существующие решения

1. Если корня нет, Кнопка найти (без кнопки создать)
2. Если корней несколько ищем от каждого. 
Если находим несколько тогда в сайдбаре появится аккордеон с картами для воркспейса. Так же дедуп по существующему пути

Этот подход с несколькими картами, можно добавить в конфиг. 

Получается в одном сайдбаре может быть несколько карт и с одного конфига

mapward.json

{
    maps: [
    { mapUrl: './map1', baseUrl: './string'}
    ]
}


@ - указывает на baseUrl сконфигурированный под эту карту. Таким образом у каждой карты @ свой 


Можно открывать и закрывать карты как корни воркспейса в vscode


Правки:

1. Используй @ ts path alias
2. Имя нужно брать не из директории а из name в _index.json
3. Поправь вёрстку аккордеона. Аккордеон должен быть прям минималистичным, как стили в файловом менеджере. Аккуратная стрелка и небольшой текст. Сейчас багают стрелки аккордеона
4. Добавь библиотеку shared/rxjs-react которая сделает удобные биндинги для rxjs к react

5. Сейчас при ошибке валидации карты или поиска - нет лоадера, и не показывается ошибка в случае если конфиг ломаный. Просто вечное ищем карты...

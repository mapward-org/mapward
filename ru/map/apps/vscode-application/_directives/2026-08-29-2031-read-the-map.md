## Добавь в shared/bridge библиотеку которая postMessage превращает в типизированный rpc 
Удобно это сделать через rxjs я его люблю

```tsx
// kernel/bridge/config.ts
const bridge = createBridge({
    getConfig: createBridgeMethod(формат настройки придумай сам),
    watchConfig: createBridgeSubscription()

})

// adapter/use-bridge

const bridge = useBridge(bridge)

const res = await bridge.getConfig()



// apps/webview/client-provider.ts

<ProviderBridgeClient  client={createBridgeClient(bridge)}/>


// apps/bridge-handler.ts
// В app что бы можно было использовать 
const server = createBridgeServer(bridge, {
    getConfig: () => {},
    watchConfig: () => {}
})

```
Это базовая идея, можешь модифицировать под реалии транспорта vscode

## Задача

Асимметрия: у большой задачи план и вопросы держат хороший уровень абстракции, а у маленькой
план остаётся почти таким же длинным и спускается в мелочь — условно три итерации про правки
десяти файлов в одном модуле. Брейншторм при этом не мешает: поговорить о задаче нормально.
Раздражает подробный План.

## Решено

- **что правим** — промпт этапа «План»; Брейншторм не меняется.
- **кусок Плана** — одно архитектурное решение, а не модуль; первой строкой его уровень.
- **уровни** — enterprise, solution (итог solution-архитектуры), software (модули и связи между
  ними), platform (переиспользуемая платформа, её публичное API и требования), code (подход к
  коду: чистые функции, реактивность, декларативно или императивно).
- **что попадает в план** — публичное API, новые модули и понятия, связи, решения уровня кода.
  Уровень, на котором решать нечего, пропускается; у маленькой задачи обычно есть хотя бы один
  кусок software.
- **что не попадает** — файлы, строки, имена, раскладка внутри модуля, пересказ правок. В код
  спускаются по просьбе автора.
- **Брейншторм** — уровень у вопросов не помечается: это диалог, а не запись решений. Вопросы
  уровня code задавать можно.
- **решение** — новое 0040, перекрывает в 0031 раздел про раскладку куска по модулям.

## План

1. **Solution: кусок Плана — одно архитектурное решение.** Промпт
   `prototypes/base/_directives.workflow/план.md`: кусок — одно решение с уровнем первой
   строкой; в план попадает публичное API, новые модули и понятия, связи, решения уровня кода;
   не попадают файлы, строки, имена, раскладка внутри модуля. Модуль называется адресом папки,
   только когда решение про него. Пустой уровень пропускается. В код агент идёт по просьбе и
   тогда отвечает кодом, а не новым куском. Уходят правила «кусок говорит, где правка» и «в
   куске видно всё, что ты решил сам»; остальное — тред, ответы автора, пятнадцать строк,
   готовность — остаётся.
2. **Solution: решение 0040.** `ru/docs/decisions/0040-plan-is-architecture-decisions.md` с
   пятью уровнями и тем, что попадает в план. В 0031 в начале раздела про кусок плана —
   цитата-пометка о перекрытии. В `ru/docs/development-guide/directives.md` — строка этапа «План»
   и абзац про объём куска без модулей.

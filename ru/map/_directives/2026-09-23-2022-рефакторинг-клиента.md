
## Задача

Экран объекта в клиенте — одна большая фича: `compose/map-object.tsx` сам тянет метрики,
экшоны, прогоны, директивы, мету и карту детей и связывает их руками. Нужно разделить его на
фичи поменьше и связать портами, а заодно перевести клиент на MobX и держать правила слоёв
тестом.

## Решено

- **фичи** — метрики, экшоны, прогоны, директивы, мета, карта детей становятся отдельными фичами; от экрана объекта остаются шапка, вкладки видов, крошки, стрелки, меню терминалов
- **порты** — порт объявляет та фича, которой он нужен; реализацию подкладывает контекстом экран объекта; общий `ports/` — только для хоста
- **карта во фичах** — фичи получают узел живой модели и читают свои поля, снимком карту никто не держит
- **состояние** — вся логика в сторах MobX; состояние React уходит отовсюду; локальный стор — `useLocalStore(() => new Store(глобальные))`
- **ленивость** — подписка по чтению — отдельная инфраструктура (ресурс), а не часть логики стора
- **compose** — крупный, для удобства чтения композиции; без тегов разметки, `className`, хуков React и логики; можно выбор `? :`, `.map` и обработчик с одним вызовом метода стора
- **вью** — `ui` фичи — много маленьких вью: рисует теги, набор `lib/ui`, саму себя и то, что пришло пропсами; другие вью фичи не вкладывает; их собирает `compose` через `children` и рендер-пропсы; компонент не длиннее 50 строк
- **точечность** — всё готовим к точечной подписке, мелко режем потом, если упрёмся в производительность
- **граф** — для `@xyflow/react` отдельная связка, единственное исключение из правил
- **проверка** — правила слоёв держит тест

## План

**software — экран объекта раскладывается на фичи, связанные портами.** Фичи метрики, экшоны,
прогоны, директивы, мета, карта детей; экран объекта только расставляет их. Фичи друг друга не
импортируют: метрикам от экшонов нужен рисунок кнопки и запуск, метрикам от прогонов — сколько
идёт и открыть последний, экшонам от прогонов — сколько идёт; реализацию подкладывает экран
контекстом. Карту фичи получают портом: живой узел открытого объекта и поиск по адресу.

**platform — состояние на MobX, три вида сторов.** Глобальные (живая карта, прогоны, «ждут
ответа», список карт) создаёт точка входа и раздаёт контекстом. Сторы моста — значения метрик,
сборка компонента, состояние вида, положение узлов — подписываются по чтению, пишут методом.
Локальные — через `useLocalStore`, получают глобальные в конструкторе и освобождают подписки при
уходе компонента. Ленивость — **ресурс** в `core`: наблюдаемое значение с функцией подписки,
подписка по первому чтению, отписка без читателей, пачка за такт; на нём же файлы живой карты.
Переходники rxjs → React уходят; rxjs остаётся на стыке с мостом.

**code — правила слоёв держит тест** на компиляторе TypeScript. `compose`: без тегов разметки и
`className`, из хуков только `useLocalStore` и хуки портов, без `if`, циклов и вычислений.
`ui`: не знает `model`, `adapters` и сторов, состояние отображения — через `useLocalStore`;
вью фичи не вкладывают друг друга — собирает `compose` через `children` и рендер-пропсы, компонент
не длиннее 50 строк.
`model` и `pure-model` без React. Везде без `useState`, `useReducer`, `useEffect`, `useMemo`,
`useCallback`; направление импортов слоёв; фичи не импортируют друг друга. Исключение —
один файл связки с `@xyflow/react`.

**code — фичи читают поля узлов.** Открытый объект находится по адресу в живой модели, фича
берёт свои поля; `compose` — `observer`, крупный. Узел модели дробится: своё и собранное — по
частям (индекс, метрики, экшоны, директивы, этапы); снимок для сервера и MCP собирается из тех
же частей.

**software — реестры.** Решение `0042` о клиенте с инвариантом-тестом; пометка о перекрытии в
разделе про клиента решения о раскладке пакетов; доки клиента и `core`; требование «правила
слоёв клиента проверяет тест».

## Развороты

- Сначала предлагалось резать `compose` мелко ради точной перерисовки; автор оставил его
  крупным ради читаемости, а точность — в модели и сторах.
- На реализации `ui` вышел крупными вью на экран; автор попросил много маленьких вью и сборку
  в `compose` через `children` и рендер-пропсы — это легло правилом в тест.
- Ленивую подписку сперва клали внутрь сторов моста; автор вынес её в отдельную инфраструктуру.


## 

Сейчас экшоны запускаются из директив. Но на практике это не удобно 

Некоторые действия удобно запускать по кнопке. 

Сбор же метрик - это read а не write поэтому это нельзя делать через метрики


Сразу делаем тут так же как с коллектором 

1. Скрипт 
2. Промпт
3. Кастомные типы которые могут потом появится
4. У экшонов есть логи, вывод и статус точно так же как и у метрик


Так же для экшонов нужен будет небольшой форм билдер потому что почти всегда нужно какие то данные собрать

Схемы этой формы будет храниться в экшоне


## Новый экран отслеживания метрик и экшонов

Сейчас не видно ни логов ни этапов работы экшонов 

Прелагаю сделать отдельный экран для этого. 

Чем то по смыслу похожий на github экшоны 

Видно настройки этапы логи, результаты каждого этапа


Ну и не будем показывать на каждой метрике зелёный круг, они шумят только красный если надо

Кстати прогоны тоже есть смысл как то хранить. Возможно стоит добавить git ignore файлы или в стейте редактора хранить

## Дисплей в виде react компонента

Сейчас дислпей обязательно дефлотный. Но это очень сильно ограничивает

В сложных сейсах лучше его сделать реакт компонентом. 

tailwind перевести в режим jit тогда можно писать любые его классы 

А компиляцию компонента делать через esbuild

В пропсах там приходят результаты коллекта + экшоны и вообще все необходимые параметры

По поводу безопасности не переживаем

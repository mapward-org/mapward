
## Задача

Css дисплея-компонента перебивает утилиты самой карты. Сервер собирает его tailwind-ом из классов, найденных в тексте `.tsx`/`.ts` компонента (`abstract-server/.../build-display.ts`, `tailwind()`), и клиент кладёт его `<style>` (`ComponentStyle`) после css карты, в тот же слой `utilities`. Повторённая утилита оказывается в каскаде позже и перебивает соседнюю у элементов карты.

Как проявилось 24.09 на `mapward://actors/Пауль`, вкладка «Прод» карты my-space: на панели компонента стоял `p-2`, и он перебил `pl-6` у `GridFrame` (`grid … p-2 pl-6`). Левый отступ сетки пропадал, стрелка сворачивания `CellFold` (`absolute -left-4`) уезжала за край, но только у открытой метрики: у свёрнутой компонента нет, нет и его css. Замер на стенде: подпись 24 px → 8 px, стрелка 8 px → −8 px.

Сейчас у Пауля это обойдено вёрсткой в своём `.css` без tailwind, но так может сломаться любой компонент. Заявка решения 0037 «одинаковые классы совпадают с уже написанными» верна по значениям, но не по порядку в каскаде.

## Что починить

Css компонента не должен побеждать утилиты карты. Варианты: положить его в слой ниже `utilities` у карты; ограничить его областью клетки (`@scope`); или не выпускать утилиты, которые уже есть в css карты. > [AI] Понял всё, давай переходить к плану.

> [AI] **platform — граница css компонента.** Css компонента действует только на территории компонента. Территория — элементы с меткой этого компонента и всё внутри них, **кроме кусков самой карты, которые компонент вставил в себя**. Пример такого куска: холст ставит узлами карточки объектов, а карточку рисует карта (`ObjectCard` из набора компонента). Внутри карточки опять действует css карты, а не холста. Иначе холст со своим `p-2` ломал бы отступы карточки так же, как сейчас ломает рамку сетки. Если в карточке открыт свой компонент метрики, у него своя метка и своя территория. Вложенный компонент побеждает внешний, потому что его метка ближе к элементу.
>
> Переменные темы tailwind (цвета, размеры) в границу не попадают и остаются общими на страницу. Значения у них те же, что у карты, так что ничего не перебивают, а без них компонент потерял бы цвета, которых нет у карты.
>
> Внутри территории компонент по-прежнему побеждает карту, как и сейчас.

## Задача

Сейчас дети на карте рисуются просто квадратами с подписью. Нужно превью объекта — карточка:
название с прототипом, ссылка с открытием в отдельном табе, кнопки терминала, экшонов и директив
(с поиском) и свой набор метрик. Карточки встают на карту детей, в списки, а одиночный объект —
в сетку метрик, каждый со своей вкладкой. Высоту можно ограничить, лишнее уходит в прокрутку,
иначе карточка растёт по содержимому.

## Решено

- **превью — это вкладка** — отдельного набора метрик у превью нет, это одна из групп объекта; её можно открыть и на самом объекте, а место показа выбирает группу явно
- **вкладка по умолчанию** — у группы флаг `defaultPreview: true`; она показывается, когда группу не назвали
- **где карточка** — отдельного дисплея для списков нет: у пунктов базовых дисплеев вместо `link` можно написать `object` (и `group`), тогда вместо строки рисуется карточка
- **одиночный объект** — метрика с дисплеем `object` и значением `{ object, group? }`, ставится в сетку по ключу, как любая метрика
- **вложенность** — без ограничений: захочет человек — пусть ломает свою карту, лишние запреты мешают, когда нужны
- **размер** — ширина и высота — свойство места, где карточка рисуется; на карте детей они задаются параметром рядом с `group`
- **шапка** — у экшонов и у директив разные кнопки

## План

1. **platform — превью задаётся вкладкой.** Карточка берёт у вкладки метрики и её `details-metrics-layout`. У группы флаг `defaultPreview`, наследуется вместе с группой. Флаг у нескольких вкладок — берётся первая. Флага нет и группу не назвали — у карточки только шапка. Названной группы у объекта нет — сообщение «нет вкладки такой-то», без подмены. Поля `preview-metrics-layout`, `preview-size`, `preview-style` уходят из формата; там, где они стояли на карте, их заменяет вкладка с `defaultPreview`. MCP ничего нового не получает: флаг приезжает полем в `groups`.
2. **platform — карточка там, где в данных стоит `object`.** Одна форма пункта `{ object, group? }` для всех дисплеев. У пункта `list` и узла `tree` с `object` вместо строки рисуется карточка, свои `label`, `link`, статус и экшон строки у него не рисуются; дети узла дерева раскрываются под карточкой. Коллектор карты детей сам ставит узлам `object`, в его конфиге появляется `group`; узел без `object` остаётся квадратом. Новый дисплей `object` для одиночного объекта. Объекта нет — сообщение «нет объекта такого-то». Форма описана вместе с остальными формами дисплеев.
3. **platform — размер задаёт место.** Пункт `{ object, group?, width?, maxHeight? }`, значения как в раскладках: css-строка, число — пиксели. Без `maxHeight` карточка растёт по содержимому, с ним шапка стоит, а сетка под ней прокручивается целиком. В списке и дереве ширина — вся, в клетке сетки карточка заполняет клетку, на карте детей ширина по умолчанию фиксированная. Карта детей задаёт `width` и `maxHeight` в конфиге коллектора для всех узлов; сохраняются только позиции.
4. **software — карточка — своя фича клиента, собранная через порты.** Сама она находит объект, выбирает вкладку, укладывает шапку и тело в размер и говорит, если объекта или вкладки нет. Тело — та же сетка метрик для пары «объект + вкладка», кнопки шапки — от фич экшонов, директив и терминалов. У метрик и карты детей в порте место «нарисуй объект»; круг «сетка → карточка → сетка» замыкается только в сборке вида. На холсте узел с `object` — свой тип узла с карточкой внутри, тащится за шапку.
5. **software — шапка карточки.** Имя с прототипом: клик открывает объект, ctrl + клик — табом. Кнопки: терминал, экшоны (то же меню, что в шапке экрана), директивы (новое меню с поиском в фиче директив, пункты «директива · этап», только незакрытые, выбор отправляет фразу этапа в сессию объекта карточки). Шапка экрана объекта не меняется. Терминалы и запуск этапа принимают адрес объекта параметром, а не берут его у экрана. Список терминалов и директив спрашивается только при открытом меню.
6. **code — подписка живёт, пока карточку видно.** Карточка подписывается на пару «объект + вкладка», как открытая вкладка экрана; сервер держит значение по адресу метрики. Вкладку по умолчанию выбирает клиент, на сервер всегда уходит конкретное имя; карточка без вкладки не подписывается вовсе. Ушла карточка с экрана — подписка гаснет вместе с вложенными. Холст рисует только видимые узлы; в списках отсечки нет, это осознанно.

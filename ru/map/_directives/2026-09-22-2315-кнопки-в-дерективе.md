
## Задача

Запускать этапы директивы прямо из её файла, а не с карты. Фраза «выполни этап…» должна уходить в
нужный терминал сразу, без поиска терминала и без ручного Enter.

## Решено

- **Где кнопки** — оба места: строка ссылок (CodeLens) внизу файла директивы и кнопка в заголовке вкладки редактора.
- **Какие этапы** — все этапы воркфлоу объекта подряд, без логики «следующего этапа»: многоэтапность — это просто повторный запуск этапа. Показываются всегда, и у выполненной директивы тоже.
- **Какой терминал** — тот, где эту директиву последний раз запускали кнопкой; если он закрыт — активный терминал объекта, потом первый живой, потом новый. Терминалы, открытые мимо карты, не ищем.
- **Запуск словами** — не отслеживаем: помним только запуски кнопкой, номер терминала в адрес MCP не вписываем.
- **Фокус** — терминал показывается в панели, курсор остаётся в файле. Так же и у кнопки на карте.
- **Отправка** — фраза должна запускаться сразу: сейчас она вставляется, но Enter не срабатывает.
- **Сохранение** — перед отправкой файл директивы сохраняется.
- **Решение** — новое `0032` перекрывает правило выбора получателя в `0017`.
- **Процесс Плана** (сделано по ходу, в этой же директиве) — кусок раскладывается по структурным модулям со ссылками; строка «план собран» идёт сразу под последним куском. Правки в `prototypes/base/_directives.workflow/план.md`, `ru/docs/decisions/0031-directive-as-thread.md`, `ru/docs/development-guide/directives.md`.

## План

**1. Выбор терминала.**
- [features/terminals](../../../apps/vscode-extension/src/features/terminals/) — владеет живыми сессиями.
  - `pure-model/`: чистое правило выбора (терминал директивы, если жив → активный терминал объекта → первый живой → «заводи новый»), с тестами.
  - `adapters/terminals.ts`: запись «адрес объекта + имя файла директивы → терминал последнего запуска кнопкой». По концу этапа не стирается, живёт в памяти редактора, на диск не пишется. `pickSession` остаётся для кнопки «терминал» на объекте.
- [apps/extension](../../../apps/vscode-extension/src/apps/extension/) — отправка этапа выносится из `bridge-handler.ts` в отдельный файл этого слоя; её зовут и карта, и кнопки в файле. Память для имени вкладки остаётся в `stage-tabs.ts`.

**2. Отправка фразы.**
- [features/terminals](../../../apps/vscode-extension/src/features/terminals/), `adapters/terminals.ts`:
  - текст уходит без Enter, после короткой паузы — отдельный Enter, чтобы агент видел нажатие, а не часть вставки. Паузу подобрать на Реализации руками;
  - терминал показывается без захвата фокуса — и при отправке, и при переименовании вкладки (терминал становится активным в панели, курсор остаётся где был);
  - запуск нового терминала с фразой внутри промпта не трогаем.

**3. Кнопки в файле директивы.**
- Новая фича `features/directive-buttons/` рядом с [features/terminals](../../../apps/vscode-extension/src/features/terminals/):
  - чистое правило: по пути открытого файла найти объект карты, у которого эта директива есть, и взять его воркфлоу. Файл не из `_directives` ни одной карты — кнопок нет;
  - CodeLens внизу файла: по ссылке на каждый этап;
  - кнопка в заголовке вкладки: одна, «этап…», открывает список этапов;
  - перед отправкой несохранённый файл сохраняется.
- [apps/extension](../../../apps/vscode-extension/src/apps/extension/) и `package.json` расширения: регистрация CodeLens, команды и кнопки заголовка, вызов общей отправки из п. 1; пробуждение расширения на открытие markdown.

**4. Решение и доки.**
- [ru/docs/decisions](../../docs/decisions/): новое `0032` (кнопки в файле, получатель, фокус, Enter отдельно) — черновик агента, правит автор. В `0017` у абзаца «Получателя выбирает карта…» — цитата о перекрытии.
- [packages/docs/ru](../../../packages/docs/ru/), раздел `directives`: вместо «фраза уходит в активную» — новый порядок; кнопки есть и в файле директивы.
- [ru/requirements/директивы](../../requirements/директивы/): новое требование не заводится — покрывает «директива выполняется этапами».
- `ru/docs/architecture/vscode-extension.md`: строка о фиче `directive-buttons`.

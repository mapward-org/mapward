## 1. Поправим в решении 0002 порядок коммитов вокруг запуска директивы

Включая строку 0002:248

Перед запуском коммитим файлы, которые директива будет править. Тогда их прежние
правки не потеряются, а изменения после прогона видно диффом

Коммитим точечно: рядом лежат недописанные директивы и черновики, их коммитить рано

После запуска не коммитим. Результат смотрится диффом, его часто отклоняют, правят
директиву и запускают заново. Отклоняем тоже точечно — `git restore` по тем файлам,
которые директива тронула, а не по всему дереву

## 2. Уберём из состояния поле result

Коммита может не быть вовсе — результат живёт в рабочей копии, пока человек не решит
его принять

Состояние теперь выглядит так

```json
{
  "directive": "<копия текста директивы>",
  "status": "done",
  "ran": "2026-08-29T01:25:00Z"
}
```

Поле надо убрать из существующих файлов в `_directives.state`

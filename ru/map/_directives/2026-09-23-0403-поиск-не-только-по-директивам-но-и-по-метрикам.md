
## Задача

На вкладке «об объекте» искать можно только в разделе «Директивы», по отдельной лупе. Нужен один
общий поиск по всей вкладке. Заодно вкладки видов («метрики / об объекте / прогоны») переезжают в
строку истории, чтобы не занимать свою строку.

## Решено

- **Поиск** — одно поле над всей вкладкой «об объекте», видно всегда, без лупы.
- **Что ищется** — видимый текст строки в каждом разделе; раздел без совпадений прячется, не
  совпало нигде — одна строка «не нашлось». Фильтр через `useDeferredValue`.
- **Не ищется** — подсказки справа и всплывающие описания; глубже видимого (конфиги, тексты
  директив) тоже нет.
- **Жизнь запроса** — на каждом объекте поле начинается пустым; в файлы не сохраняется.
- **Вкладки видов** — в строке истории сразу за стрелками, перед крошками, с названиями: места там
  достаточно.
- **Стрелки истории** — крупнее.

## План

1. Правило совпадения, чистой функцией. `features/map-object/pure-model/directives.ts`: общее
   `matches(query, ...тексты)` — подстрока без регистра, дефисы и подчёркивания как пробелы;
   `matchDirectives` становится его частным случаем. `features/map-object/_meta/pure-model/meta.ts`:
   `searchMeta(object, query)` отдаёт по разделам совпавшие строки — «Объект»: имя, адрес, путь на
   диске, ключ и значение каждого поля; «Метрики»: подпись и ключ; «Этапы директив»: имя;
   «Экшоны»: подпись и ключ; «Директивы»: имя файла с датой. Пустой запрос отдаёт всё. Тесты рядом.
2. Поле поиска. `_meta/compose/meta-screen.tsx` держит запрос и `useDeferredValue`;
   `_meta/ui/meta-view.tsx` рисует поле над разделами вне прокрутки, прячет пустые разделы, пишет
   «не нашлось», Escape очищает, фокус само не забирает. `_directives/compose/directive-section.tsx`
   теряет свою лупу и поле, получает отобранный список. `compose/map-object.tsx` даёт мета-экрану
   ключом адрес объекта — на новом объекте поле пустое.
3. Вкладки в строке истории. `ui/breadcrumbs.tsx` получает место под вкладки за стрелками, стрелки
   крупнее и с большей площадью нажатия, приглушены только крошки. `ui/view-tabs.tsx` теряет свою
   строку с отступами. `compose/map-object.tsx` переносит вкладки в строку истории.


## Задача

При переключении вкладки метрик клетки на время показывают «не собиралась», хотя значение уже
собрано, и только потом подгружается настоящее. Раньше собранное стояло сразу, а досчёт шёл в
фоне. Заодно — перестроить серверный модуль «объект карты», в котором лежит почти всё, и сделать
модель карты декларативной.

## Решено

- **причина баги** — переключение вкладки заводит новую подписку; пока не пришёл её первый снимок, клиент рисует пустоту как «не собиралась», а сервер шлёт первый снимок только после полного чтения карты и кэша всех метрик вкладки
- **требование к показу** — хватит, чтобы уже известное сервером приходило сразу, а «ещё не пришло» не выдавалось за «не собиралась»
- **карта** — одна модель на MobX, общая для сервера и клиента, живёт в `core`: классы модели вместе с наследованием, мерджем и подстановками; rxjs-модель с цепочками `switchMap` отменена — зависимости в ней неявные
- **файлы** — наблюдаемое значение, которое читается при подписке и отпускается без подписчиков; на сервере с диска, на клиенте по мосту
- **мост** — по мосту едет содержимое файлов карты с подпиской, а не собранная карта и не JSON Patch; читать можно только внутри папки карты
- **клиент** — тоже на MobX, компоненты перерисовываются по прочитанным полям
- **local-first** — не берём: писатель один, файлы — источник истины, клиент в модель не пишет
- **свежесть** — слежка за файлами, на которые модель сослалась; кнопка «перечитать» рядом с навигацией
- **раскладка сервера** — фичи карта, метрики, директивы, дисплеи, запуск; фичи связаны портами, которые объявляет потребитель
- **классы** — юзкейсы и сервисы на сервере классами: зависимости в конструктор, данные вызова в метод; домен — чистые функции; сборка вручную, без контейнера
- **порты** — каждый класс берёт только нужные порты; порт файлов делится на чтение, запись и слежку
- **реестры** — решение поверх решения о раскладке пакетов, правка архитектурных док

## План

План этапом не писался; поверх сделанного по прошлому плану (фичи, классы, порты, мгновенный
первый снимок метрик, «загружается…», кнопка «↻») решено:

**solution — модель карты общая, в `core`, на MobX.** Файл карты — наблюдаемое значение с
загрузкой при подписке. Объект — класс с вычисляемыми полями: своё из файлов, остальное из
прототипа и подстановок. Источник файлов — порт: сервер даёт диск с вотчером, клиент — мост.

**solution — мост возит файлы.** Клиент подписывается на файл и папку карты по пути внутри неё;
сервер отвечает из своей модели и шлёт новое содержимое при изменении.

**software — клиент читает модель сам.** Экран карты берёт объект из своей модели в `core`, а не
собранную карту с сервера; компоненты — `observer`.

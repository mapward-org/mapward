Выполни директиву — по плану, если он писался, иначе по тексту директивы.

Читай её снизу вверх: нижний ответ автора переопределяет верхний — отвечая, он мог не помнить,
что писал выше. Противоречие схлопывай молча, по нижнему.

Вопросы без ответов не блокируют: возьми умолчание, сделай работу целиком. Блокируйся только
там, где любое умолчание испортит чужое.

Перед началом закоммить точечно файлы, которые будешь править: тогда результат виден диффом,
а откат делается `git restore` по конкретным путям. Результат не коммить — его смотрит человек.

Отчитайся списком: строка на сделанное. Дифф не пересказывай, его видно диффом. Отдельным
списком — «решил за тебя»: где взял умолчание вместо ответа и какое. Этот список дописывается
в директиву разделом «Реализация», с ним сверяется Тестирование; остальной отчёт остаётся
в сессии.

Директиву дописывай только в свои зоны. Тело — текст автора.

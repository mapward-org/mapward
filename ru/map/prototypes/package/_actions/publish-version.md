Как выпускать версию пакета.

Версии в репозитории ведёт changeset, релиз идёт через github versions,
руками в `package.json` версию не правим.

Порядок:

- `pnpm changeset` — описать изменение и выбрать уровень (patch/minor/major)
- закоммитить получившийся файл в `.changeset/`
- дальше версию поднимает и публикует релизный workflow, локально ничего не публикуем

Создай пустой пакет по этому объекту карты.

Перед запуском в `_index.json` объекта должны быть заполнены props:

- `codePath` — где будет лежать пакет, относительно корня репозитория
- `docsPath` — где будет лежать его дока
- `packageName` — имя пакета в npm

Что сделать:

- завести пакет по `codePath`: `package.json` с именем `packageName`, `src/index.ts`,
  `tsconfig.json` и конфиг сборки как у остальных пакетов репозитория
- завести доку по `docsPath`: что за пакет и зачем
- ничего не публиковать и не versioned — этим занимается экшон publish-version

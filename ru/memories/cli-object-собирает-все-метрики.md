---

`node apps/cli/dist/cli.mjs object mapward://packages/core` не отвечает быстро: он собирает
метрики объекта вместе с дорогими (агентскими), и вызов упирается в таймаут оболочки. Посмотреть
поля и вкладки объекта свежей сборкой так нельзя.

Одну метрику свежей сборкой даёт `node apps/cli/dist/cli.mjs metric <адрес метрики>` — секунды.
Вкладки и поля — живой MCP `read_object { metrics: [], fields: [...] }`, если новое поле старой
сборке не нужно; иначе свой `mapward mcp` по stdio. (2026-09-24)

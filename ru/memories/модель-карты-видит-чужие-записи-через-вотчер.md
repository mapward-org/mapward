С решения 0041 сервер не перечитывает карту на каждый вызов: `MapModel` держит её потоками и
обновляет по вотчеру (пачка ждёт тишины ~40 мс). Свои записи сервера — через `MapModel.writer`
(директива, состояние, реплика, `map-state.json`) — видны сразу. Кэш и логи метрик пишутся
мимо обёртки: в модель они не входят.

На чём спотыкаются:

- **Тест с фейковым `watch: () => () => undefined`** не увидит файл, который тест дописал в
  дерево сам после первого чтения: вотчер молчит. Либо пиши через `model.writer(files)`, либо
  зови `model.reload(ref)`, либо заводи новую модель на каждый вызов (так сделан `readMap` в
  `map-model.test.ts` и `metric-store.test.ts`).
- **Агент записал файл карты `Write`-ом и сразу зовёт MCP** — модель могла ещё не получить
  событие. Директиву и объект `DirectiveLocator` при промахе ищет второй раз после
  `reload`; для остального (`read_object` нового объекта) — перечитать кнопкой «↻» или
  повторить вызов.
- Сравнить новую модель со старым чтением можно было только временным тестом: старый
  `read-map.ts` берётся из git (`git show <sha>:packages/abstract-server/src/features/map-object/application/use-cases/read-map.ts`)
  и кладётся рядом с правкой импортов. На настоящей карте 2026-09-23 результат совпал целиком.

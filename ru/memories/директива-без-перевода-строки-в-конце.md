description: автор сохраняет директиву без перевода строки в конце — реплику отдавай в finish_directive { reply }, а не `>>`
---

Редактор автора оставляет файл директивы без `
` в конце. Реплика, дописанная `>>` или
heredoc-ом, встаёт вплотную к ответу автора, и в markdown ответ уходит внутрь цитаты.

С 2026-09-23 реплику дописывает сервер: `finish_directive` с параметром `reply` сам ставит пустую
строку перед ней. Пока живой сервер старый (параметра нет — отказ «нет параметра reply»),
по-прежнему проверяй конец файла `tail -c 1 файл | od -c` и дописывай недостающий `
`.

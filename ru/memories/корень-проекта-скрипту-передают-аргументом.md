description: скрипт-коллектор получает в окружении только MAPWARD_MAP_PATH/OBJECT_PATH/OBJECT_NAME/OBJECT — корень проекта (mapward://@) передают аргументом в run
---

Подстановка `${{ … }}` работает в `run`, но не внутри тела скрипта, а в окружении корня
проекта нет: приезжают `MAPWARD_OBJECT_PATH`, `MAPWARD_MAP_PATH`, `MAPWARD_OBJECT_NAME`,
`MAPWARD_OBJECT`. Карта лежит в `ru/map`, проект — двумя уровнями выше, и вычислять это
в скрипте значит зашить структуру репозитория.

Поэтому корень передаётся аргументом:

```json
{ "kind": "script", "run": "node \"${{ mapward:// }}/_metrics/имя/скрипт.mjs\" \"${{ mapward://@ }}\"" }
```

Так сделаны метрики вкладки «Агенту» на корне (`_metrics/agent-*`) и `package-deps`.
Скрипту, которому хватает карты, аргумент не нужен — `directive-runs` и `children-list`
обходятся `MAPWARD_MAP_PATH`.

Путь в аргументе приходит windows-виду (`d:\my-space\mapward`), поэтому в скриптах он сразу
проходит через `replaceAll("\\", "/")` — как это делает `prototypes/system/_metrics/requirements/status.mjs`.

Дата наблюдения: 2026-09-21.

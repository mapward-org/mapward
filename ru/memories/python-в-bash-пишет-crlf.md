---
description: python3 из Bash на Windows пишет файлы с CRLF — open(..., newline="") при правках кода скриптом
---

Правка файла скриптом `python3` (обход потерянных обратных слэшей в оболочке) по умолчанию
переводит все строки в CRLF, и дифф показывает файл переписанным целиком. Открывать и писать с
`newline=""`. Обратные слэши внутри heredoc в `python3 - <<'EOF'` тоже теряются — скрипт с
ними пиши `Write` в файл и запускай по пути. `pnpm add` к тому же переписывает
`pnpm-workspace.yaml` (сортирует каталог, стирает комментарии) — после него сверять дифф. (2026-09-23)

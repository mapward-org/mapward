---
description: viewColumn группы VS Code пересчитывается при любой перестройке окна, а TabGroup пересоздаётся — помнить группу нечем; узнавать по содержимому. Открытие без колонки обходит закреплённую группу
---

- `viewColumn` — порядковый номер группы на экране. Разрезали, добавили или закрыли группу — номера
  остальных групп съезжают, и запомненный номер указывает уже на другую группу.
- Объекты `vscode.TabGroup` хост расширений пересоздаёт при каждой перестройке групп
  (`$acceptEditorTabModel`; это вычитано из исходников VS Code, живьём не проверял), поэтому ни по ссылке, ни через `WeakMap` их не запомнить. У групп нет
  id в API. Раскладка директив (`features/directive-layout`) поэтому определяет зону по содержимому
  вкладок.
- `showTextDocument` без `viewColumn` не открывает файл в закреплённой группе: VS Code уводит его в
  соседнюю. С явной колонкой файл попадает туда, куда указано.

---
description: tsdown расширения берёт abstract-server из src по paths, а не его dist — плагины сборки сервера нужны и в конфиге расширения
---

`apps/vscode-extension/tsdown.config.ts` бандлит `@mapward/*` по `paths` из `tsconfig.base.json`,
то есть из `packages/*/src`, а не из `dist` пакета. Всё, что сервер делает своим
`tsdown.config.ts` (например `?raw` для css tailwind), расширение должно уметь само — поэтому
плагин `raw` лежит отдельным `packages/abstract-server/tsdown.raw.ts` и подключён в обоих
конфигах. cli, наоборот, берёт `dist` сервера. (2026-09-23)

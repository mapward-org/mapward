description: метрику после правки сервера проверяют `node apps/cli/dist/cli.mjs metric <адрес>` — живой MCP для этого не годится
---

Живой MCP обслуживает собранный `dist` открытого расширения и до его перезапуска показывает
старое поведение — [`живой-mcp-это-собранная-сборка.md`](живой-mcp-это-собранная-сборка.md).
Поэтому правку в сборе метрик проверяют через cli:

```
pnpm build
node apps/cli/dist/cli.mjs metric "mapward://packages/core/_metrics/files"
```

Команда поднимает тот же сервер на портах node, гоняет пайплайн целиком (как кнопка обновления)
и печатает значение json-ом. Рядом `object [адрес]` — объект с метриками, `maps` — список карт.

`cli.mjs` не бандлит сервер: он тянет `@mapward/abstract-server` из `dist` пакета, так что
пересобрать надо именно его, а `pnpm build` с корня делает это разом.

Проверено 2026-09-20 на встроенном трансформе `git-status`: тесты его проходили, а сошлась ли
разметка на настоящем репозитории, показал только такой прогон.

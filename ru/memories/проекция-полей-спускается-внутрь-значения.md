---
description: в fields у read_object путь можно вести внутрь value — metrics.value.ok даёт здоровье всех метрик объекта на пару килобайт
---

Дока `read_docs { section: "mcp" }` показывает проекцию до `metrics.value`, и кажется, что
значение приходит целиком или никак. На самом деле путь идёт дальше внутрь значения:

```json
{ "address": "mapward://", "group": "продукт", "refresh": "on-display",
  "fields": ["metrics.key", "metrics.value.ok", "metrics.value.collected",
             "metrics.value.updatedAt", "metrics.value.busy"] }
```

Приходит ключ и здоровье каждой метрики без единого `data` — девятнадцать метрик корня
укладываются в пару килобайт вместо сотни. Это рабочий вызов для вопроса «всё ли собирается»
после правки набора метрик: `collected: false` отличает несобиравшуюся от собранной пустоты,
а `updatedAt` показывает, какие остались с кэшем (`manual` при `on-display` не пересчитываются).

За значениями после этого идут точечно: `metrics: ["package-deps"]` с
`fields: ["metrics.value.data"]` — названная одна метрика бюджетом не режется.

Проверено 2026-09-21. Рядом: [[раскладка-вкладки-через-mcp-не-видна]],
[[обзор-карты-без-fields-раздувается]].

Правила слоёв клиента (решение 0042) проверяет не линт, а тест с корня —
`tests/client-layers.test.ts`. Его не видно ни в typecheck, ни в тестах пакета
(`pnpm vitest run packages/abstract-react-client` его не берёт), он падает только в полном
`pnpm test`.

В `compose/` нельзя: теги, `className`, шаблонные строки, функции с телом, вычисления.
Вычисления — в стор или `pure-model`, разметка — в `ui` маленькими вью.

В `ui/` вью не рендерит свои же компоненты (`<Spinner>` внутри `TurnItem` — отказ: «вью собирает
compose через children и рендер-пропсы»). Общий кусок разметки там — строкой классов, а не
компонентом; компонент из `lib/ui` импортировать можно. 2026-09-27.

Файл связки с библиотекой холста (`features/objects-map/ui/flow.tsx`) — исключение, записанное
в тесте путём. Переименовал или перенёс фичу холста — поправь путь там же, иначе тест требует
убрать из связки состояние React, без которого `@xyflow/react` не работает. 2026-09-27.

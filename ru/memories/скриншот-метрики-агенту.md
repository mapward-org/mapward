`call_plugin _plugins/screenshot capture { metric }` пишет PNG в `ru/map/.mapward/screenshots/<объект>__<ключ>.png`
и отдаёт `path` — смотреть через `Read` по нему. base64 — только с `base64: true`.

Ловушка Playwright (починено 2026-10-30): строка в `waitForFunction`, которая сама вычисляется
в функцию (`"(quiet) => {…}"`), не вызывается, а считается истинным значением — ожидание
кончается за ~15 мс, и снимок ловит «собирается…»/«загружается…». Условие передаётся
выражением-вызовом: `` `(${SETTLED})(${QUIET_MS})` ``. Признак регресса — `capture` отвечает
быстрее 0,7 с окна тишины.

Холст снимается в размер окна: `fullPage` его не растягивает, низ обрезается — давай `height`.

Свой зонд — playwright-core из `~/.mapward/screenshot/node_modules`, скрипт в scratchpad, путь
к модулю аргументом (см. [[обратный-слэш-в-командах-оболочки-теряется]]). Собранный плагин
лежит в `ru/map/.mapward/plugins/*_screenshot.cjs` — по нему видно, какой код реально бежит.
Правка встроенного плагина — в `packages/plugins/registry/<имя>` и копии `ru/map/_plugins/<имя>`,
потом `node packages/plugins/scripts/bundle-plugins.mjs` (пересобирает `sources.generated.ts`).

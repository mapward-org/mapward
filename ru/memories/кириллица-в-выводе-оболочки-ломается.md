---
description: вывод скриптов с русским текстом приходит в терминал нечитаемым — писать в файл и читать его Read
---

Содержательное в этом репозитории написано по-русски: имена требований, решений, разделов
реестра. Вывод команды в терминал приходит в кодировке консоли Windows, и кириллица в нём
превращается в мусор вида `������`. Ломается именно показ — файлы на диске целы.

Обход: писать вывод в файл (`PYTHONIOENCODING=utf-8 python … > "$TMPDIR/out.txt"`) и читать
файл инструментом `Read`, который отдаёт UTF-8 как есть. Списки файлов, фронтматтер, дампы
деревьев — всё через файл.

Ответы MCP этим не задеты: они приходят по своему каналу и читаются нормально. Поэтому первый
выбор — спросить карту, а не скриптовать по диску.

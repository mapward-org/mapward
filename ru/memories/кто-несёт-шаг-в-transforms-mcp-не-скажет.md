Вопрос «у каких метрик карты в `transforms` стоит `{ "kind": "git-status" }`» через MCP
не закрывается. `read_object` умеет отобрать метрики по **ключу**
(`fields: ["address", "metrics.key", "metrics.owner"]`, любая глубина, почти бесплатно), но по
содержимому конфига — нет, а `fields: ["metrics.config"]` по всей карте бюджет заменит
маркерами `{ truncated }`: конфиги самое тяжёлое в ответе.

Считается так:

```
grep -rl '"kind": *"git-status"' ru/map --include=config.json
```

Это тот случай, когда обход репозитория мимо карты оправдан: спрашивается не значение метрики,
а то, где она объявлена.

# Память агентов

Индекс: строка на файл, ничего кроме. Сам факт живёт в файле, сюда попадает только то, по
чему видно, стоит ли его открывать.

Формат строки — область первым словом, дальше суть и ссылка:

```
- карта: состояние прогона пишет сервер, `.state.json` руками не трогают — [файл](состояние-прогона.md)
```

Области — по объектам карты и по крупным темам: `карта`, `core`, `abstract-server`,
`расширение`, `требования`. Папками не раскладываем: индекс дёшев, отбирает читающий.

Файл наблюдения — frontmatter с `description` и текст:

```markdown
---
description: одной строкой, по ней решают, открывать ли
---

Само наблюдение. Дата, если оно может протухнуть.
```

Что сюда кладём и что нет — [`../docs/development-guide/memories.md`](../docs/development-guide/memories.md).
Коротко: не общеизвестное и не выводимое из структуры репозитория и карты. Решения — не сюда,
они заводятся директивой.

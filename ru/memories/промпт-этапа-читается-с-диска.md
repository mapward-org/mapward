---

`read_object` отдаёт `workflow` списком этапов: `name`, `order`, `marksDone`, `path`, `owner`.
Раньше текста этапа через MCP было не достать, и его читали файлом по `path` — у карты
«Mapward (ru)» этапы лежат в `prototypes/base/_directives.workflow/`.

С 2026-09-20 текст отдаётся вызовом, и отметки о прогоне это не ставит:

```json
{ "address": "mapward://", "stage": "Проверка" }
```

Имя ищется регистронезависимо, файл берётся из модели объекта — значит найдётся и
унаследованный от прототипа. У этапов, которые инструмент даёт по умолчанию, файла нет вовсе,
и с диска их текст не достать никак.

`run_directive` по-прежнему отдаёт промпт запускаемого этапа — с хуком, промптом объекта и
отметкой о начале прогона. Это разные вещи: `stage` — посмотреть, `run_directive` — работать.

Решение `0022`, требование `mcp/текст-этапа-читается-не-запуская-его.md`.

Совет «начни с обзора: `read_object` с глубиной и без метрик» на корне этой карты даёт
~55 КБ и уезжает в файл, хотя `metrics: []` стоит. Документация объясняет вес значениями
метрик, но здесь их нет: вес дают `layout`, `workflow` и `actions`, которые повторяются на
каждом из двух десятков объектов — пять этапов с путями и четыре экшона у каждого пакета.

Обзор, который влезает в один экран:

```json
{ "depth": 2, "metrics": [],
  "fields": ["address", "name", "prototypeName", "path", "props",
             "directives.files", "directives.total", "directives.new"] }
```

`workflow` и `actions` добавлять в проекцию только когда они и есть вопрос: у наследников
они одинаковые и отличаются лишь полем `owner`.

Проверено 2026-09-20 на `mapward://` карты «Mapward (ru)».

---
description: F5 при установленном mapward поднимает две копии расширения — у них разные id, dev-хост падает с кодом 134
---

`scripts/package-vsix.mjs` упаковывает расширение под именем `mapward` (id `mapward.mapward`),
а в `apps/vscode-extension/package.json` имя `@mapward/vscode-extension`. Для VS Code это два
разных расширения: отлаживаемое установленное не подменяет, в Extension Development Host
грузятся оба.

Симптом: окно dev-хоста открывается и сразу закрывается. Лога `exthost` у окна нет вовсе,
поэтому `grep mapward` по `exthost.log` ничего не находит. Причина видна только в двух местах:

- `logs/<сессия>/window<N>/renderer.log` — `Cannot register multiple views with same id mapward.map`;
- `logs/<сессия>/main.log` — `extensionHost … crashed with code 134`.

Окна dev-хоста — это `window*`, у которых нет папки `exthost`.

Лечится `--disable-extension=mapward.mapward` в `args` конфигурации в `.vscode/launch.json`
(поставлено 2026-09-22). Удалять установленную копию не нужно.

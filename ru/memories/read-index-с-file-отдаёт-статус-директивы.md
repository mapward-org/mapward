---
description: read_index с file возвращает не только текст директивы, но и её status и path — обзорный read_object ради статуса не нужен
---

Дока `mcp` про параметр `file` говорит только «отдаёт markdown по имени», и из-за этого статус
директивы («не `done` ли она») идут выяснять обзорным `read_object` по корню — а он тяжёлый
даже с `metrics: []` и проекцией.

На самом деле `read_index { address, file }` возвращает объект вида:

```json
{ "name": "2026-09-20-0515-git-status.md",
  "path": "d:/my-space/mapward/ru/map/_directives/2026-09-20-0515-git-status.md",
  "status": "new",
  "text": "…" }
```

То есть для этапа, который начинается с проверки статуса директивы (например, сжатие
в начале «Реализации» не трогает закрытую), хватает одного этого вызова.

Проверено 2026-09-20 на `mapward://` карты `ru`.

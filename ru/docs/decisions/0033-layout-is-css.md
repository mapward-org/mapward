# Раскладка — это css: сетка растёт, условия по ширине настоящие

> Черновик агента по директиве `2026-09-23-0006-доработки-лейаута.md` — правит автор.

Сетка метрик была прибита к высоте окна, а высоты рядов карта писала руками
([0029](0029-metric-grid-rows.md)). Развёрнутое дерево файлов сжимало все ряды — вылезать было
некуда, прокручивать нечего. Агенты, подбирая `fit-content` и `minmax`, ошибались раз за
разом. Словарь раскладок под ширину, обещанный в [0003](0003-index-format.md), не работал:
бралась последняя раскладка, условие выбрасывалось.

## Сетка растёт, прокручивается область

Код высоту сетки не задаёт: она растёт по содержимому, а прокручивается область метрик целиком.
Шапка, директивы и вкладки стоят на месте. Верхние метрики уезжают при прокрутке — эту цену
приняли: сжатые до нечитаемого ряды хуже.

Растянуть сетку на всё окно (шапка, подвал, середина до низа) раскладка может сама:
`"height": "100%"` в `style` и ряд `1fr`. Таб одной метрики остаётся во всю высоту — там метрика
и есть экран.

## Код ничего не подставляет

Ни высот рядов, ни потолков у клеток, ни складывания колонок в узком сайдбаре. Такие умолчания
на практике неудобны: их приходится помнить и перебивать. Всё растёт; что нужно, раскладка
пишет сама.

Одно исключение — ряды прижаты кверху (`align-content: start`). Когда сетке досталось больше
места, чем нужно метрикам (`height: 100%` без ряда `1fr`), css иначе растягивает ряды на весь
остаток, и метрики расползаются по экрану.

## Как в css

Своего языка раскладки нет — агенты знают css и путаются в кастоме. Ключ словаря раскладок —
настоящее условие `@container (…)` по ширине области метрик; порядок ключей — порядок правил,
побеждает последний подошедший. Не подошёл ни один — метрики стоят стопкой, как в css без
правил. Метрика, названная хотя бы в одном варианте, показывается; в варианте, где её нет,
скрыта.

Дока раскладок — примеры со схемами, а не рассказ: повествование агенты теряют на больших
контекстах.

## Что перекрыто

- [0029](0029-metric-grid-rows.md), «Высоты пишет карта, а не код»: вкладка больше не прибита к
  окну, и высоты рядов пишутся, только когда нужны. Раздел «Метрика без раскладки не
  показывается» остаётся в силе.

Раскладку под ширину из [0003](0003-index-format.md) это решение не перекрывает, а доделывает:
там она и была задумана условиями `@container`, в коде их не было.

## Инвариант

Сетка метрик не получает высоты от кода, кроме таба одной метрики: появилась высота или потолок
по умолчанию — нарушение.

Каждый ключ словаря раскладок доходит до браузера условием `@container` в порядке ключей:
вариант, выбранный кодом, а не css, — нарушение.

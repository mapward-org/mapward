# Css компонента действует только на его территории

> Черновик агента по директиве `2026-09-24-1530-css-компонента-перебивает-классы-карты.md` — правит автор.

Css компонента метрики собирается tailwind-ом в тех же слоях, что у карты
([0037](0037-component-display.md)), и ложится своим `<style>` ниже css карты. Одинаковые классы
совпадали по значениям, но не по месту в каскаде: `p-2` компонента оказывался последним и
перебивал `pl-6` у рамки сетки (`p-2 pl-6`) — левый отступ пропадал, стрелка сворачивания уезжала
за край, и только у открытой клетки. После того как компонентами стали и встроенные метрики,
сломаться могла любая.

## Территория

Правила css компонента действуют только на его территории — внутри элементов с его меткой
`data-mw-component`. Метку ставит карта: на клетку компонента и на его слой всплывающих окон —
элемент в `body`, который компонент получает хуком `useFloatingLayer()` (функцией: слой
заводится, когда меню открывают). Вынесенное порталом прямо в `body`, мимо слоя, остаётся без
его классов.

Внутри территории не действуют куски карты, которые компонент вставил в себя: карточка объекта
`ObjectCard` помечена `data-mw-map`, и в ней снова css карты. Кнопки, которые компонент отдал
карточке, — опять его территория. Вложенный компонент — своя метка и своя территория.

Внутри территории компонент по-прежнему побеждает карту.

## Как

Сервер заворачивает css компонента в `@scope` по метке: внутри слоя `utilities`, чтобы порядок
слоёв с картой не менялся. Метка — отпечаток самого css, у двух клеток одного компонента она
общая. Переменные темы, начальные значения переменных tailwind, `@property` и `@keyframes` в
границу не попадают: значения у них те же, что у карты, а без них компонент потерял бы цвета,
которых у карты нет.

## Отвергнуто

- **Css компонента слоем ниже карты** и **выкинуть повторы** — ломают сам компонент зеркально:
  у его `p-2 pl-6` выигрывает `p-2` карты.
- **tailwind-merge** — правит строку классов одного элемента, а ломался порядок правил в css.

## Инвариант

У открытой клетки с компонентом отступ рамки сетки тот же, что у свёрнутой. Тест
`tests/component-css-scope.test.ts` проверяет это в Chromium.

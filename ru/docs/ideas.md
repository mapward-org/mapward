## Простые

1. Сохранять состояние открытости папки с файлами между переходами по докам
2. В mcp есть инструкция по всем метрикам и работе с картой
3. метрика files - вотчер
4. На всех вьюхах метрик есть возможность вывести статус - кайне важная фича для метрики
5. Метрика md текст, для описаний пояснений и пд

- Во время сбора метрики  показывать лоадер а не 3 точки + Возможность, посмотреть логи процесса бы где нибудь
- Добавить кнопку для просмотра файлов метрик

## Сложные

1. Сделать архитектурной карты вывод. 
    Для этого: Система плагинов метрик нужно продумать
    Сделать плагин который: Засмечается классы модулей, дальше на основе классов выводится дерево модулей, и связи между нимы выводятся из ссылок typescript Этакий архитектурный ревьювер. 

2. Зависимости в коллекте
  Список файлов на которые зависим. Можно взять с них хэш и сравнивать

3. Создание mcp для чтения проекта

4. Форовый арекстратор сбора метрик, что бы можно было переходить по карте и их значения кэшировались

5. Рисовать на карте как miro для проектирования и удобства создания базовых объектов, и дальнейшая работа с ними

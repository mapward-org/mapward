# display

Типы дисплея-компонента метрики для чужих проектов — решение
[0037](../decisions/0037-component-display.md). Его ставят в проект dev-зависимостью, чтобы
компонент метрики проверялся `mapward display check`, а не угадывался.

```
src/
  index.ts    DisplayProps<Data>, пункты списка и дерева, объявления кусочков набора
```

Кода здесь нет, только типы и `declare`: на карте `import … from "@mapward/display"` подменяет
клиент, и компонент получает те же кусочки, которыми нарисована карта. Реализация набора живёт
в `abstract-react-client` (`_metrics/ui/display-kit.tsx`) и проверяется против этих типов
`satisfies` — разойдутся, не соберётся клиент, а не сломается чужой компонент.

Пакет ни от кого из своих не зависит: он публикуется для проектов, у которых mapward нет в
зависимостях, и тянуть за собой `core` ему незачем. React — только типами, peer-зависимостью
`@types/react`.

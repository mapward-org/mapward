# core

Связь сторон: то, что серверу и клиенту нужно понимать одинаково. Границы пакета — решение
[0014](../decisions/0014-client-server.md), слои — [0015](../decisions/0015-package-layout.md).

## Структура

```
src/
  contracts/     контракты взаимодействия; делятся так, как удобно читать
  lib/           переиспользуемые утилиты и типы — например базовый дженерик контракта
  model/         чистые функции и типы доменной модели карты: разбор своего у объекта,
                 наследование, мердж, подстановки, этапы по умолчанию
  live/          живая модель карты на MobX: ресурс, файлы на нём, объект — класс с
                 вычисляемыми полями по частям
  index.ts       точка входа в пакет
```

## Что сюда попадает

Не всё общее, а то, что доказало необходимость: дублирование по умолчанию, вынос — по
реальному прецеденту переиспользования, и смотрит его человек.

Сегодняшние кандидаты: типы объекта карты, адресация, схемы `_index.json` и метрик, сигнатуры
вызовов и подписок. С решения [0041](../decisions/0041-server-map-model-and-classes.md) здесь же
сборка карты — наследование, мердж, подстановки — и живая модель поверх неё: её держат и
сервер, и клиент, а отличается у них только источник файлов (`FileSource`: у сервера диск, у
клиента мост). Глобы и промпты — сервер; раскладка сетки и иконки файлов — клиент.

В основе — `Resource`: наблюдаемое значение с функцией подписки. Подписка открывается по первому
чтению и закрывается, когда читателей не осталось, а пришедшее за такт кладётся одним действием
MobX; `once` — ресурс из одного запроса. Им же пользуются сторы моста у клиента (решение
[0042](../decisions/0042-client-features-mobx-and-layer-test.md)).

Живая модель — `LiveFiles` и `LiveMap`. Файл — ресурс: читается источником, когда на него
подписались, и отпускается без подписчиков. Объект делится на части — индекс, метрики, экшоны,
директивы, этапы, — и у каждой своё, собранное с прототипом и подставленное считаются порознь:
правка метрик не пересчитывает экшоны. Объект сам отвечает типом `MapObject`, поэтому любой код,
читающий объект, подписывается только на прочитанные поля. Снимок для сервера и MCP собирается
из тех же частей; поле объекта держит прежнее значение, пока файл перечитывается, и
неизменённая ветка приходит тем же объектом. Готова ли карта целиком, говорит `snapshot`:
`undefined` — ещё читается.

## Правила

`core` не зависит ни от кого. Ни от платформы, ни от пакетов, ни тем более от приложений —
это проверяет `tests/platform-independence.test.ts` и тест направления зависимостей.

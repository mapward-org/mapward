# Как устроено внутри

Доки про внутреннее устройство: слои, папки, правила импортов. По одному на пакет и на
приложение, правила общие — решение [0015](../decisions/0015-package-layout.md).

- [Границы между пакетами](packages.md) — кто от кого зависит и что кому знать.
- [core](core.md) — контракты, модель, утилиты.
- [abstract-server](abstract-server.md) — юзкейсы и домен.
- [abstract-react-client](abstract-react-client.md) — интерфейс.
- [docs](docs.md) — текст инструмента, едущий вместе с ним.
- [Расширение VS Code](vscode-extension.md) — реализация портов обеих сторон.
- [CLI](cli.md) — сервер без редактора.

Снаружи инструмент описан в [`packages/docs/ru/`](../../../packages/docs/ru/): что такое
объект, из чего собирается метрика, как работают директивы. Граница простая — здесь то, что
видит пишущий карту, там то, что видит пользующийся ею. Те доки едут к пользователю пакетом,
эти остаются у нас — решение [0016](../decisions/0016-agent-context.md).

Как и остальные доки, это проекции решений из [`../decisions/`](../decisions/): дописываем по
ходу, но источник истины там, и разошлись — прав решение.

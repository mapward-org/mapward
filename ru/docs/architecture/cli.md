# CLI

Приложение: реализует порты сервера и делает с картой то же, что редактор, только из
терминала — поднимает MCP-сервер или выполняет серверную команду, например собирает метрику.
Решение [0014](../decisions/0014-client-server.md).

## Структура

```
src/
  cli.ts            разбор команд
  ports.ts          реализации портов сервера на node
  stdio.ts          транспорт MCP: json на строку
  platform.ts       одна платформа на карту: живая по .mapward/platform.json, прокси до неё,
                    свой MCP по http и запись о себе
```

Клиента cli не тянет — команда, печатающая метрику, ничего не рисует.

## Команды

```sh
mapward maps                  карты, видимые отсюда
mapward metric <адрес> [карта]  собрать метрику и напечатать результат
mapward mcp [карта]           mcp-сервер над картой; живая платформа есть — клиент к ней
mapward plugin add <имя> [папка]  скопировать встроенный плагин в карту
mapward plugin check <путь> [карта]  проверить плагин
```

`metric` у метрики с изменяющим методом `refresh` (`agent.ask`) зовёт его — спрашивает заново;
у остальных печатает первое значение её запроса для агента. `.wasm` сборщика cli берёт из своего
`node_modules`.

`plugin check` печатает шаги `checkPlugin` сервера (`features/plugins`, `CheckPlugin`): сборка с
местом ошибки, процесс и рукопожатие, самоописание, метрики карты, которые на плагин ссылаются.
Тот же ответ у инструмента MCP `check_plugin`.

## Одна платформа на карту

`mapward mcp` сначала читает `<карта>/.mapward/platform.json` и пробует адрес из него. Отвечает —
команда только проводник: строки stdio уходят живой платформе `POST`-ом, своих процессов плагинов
нет (`proxyMcp`). Нет — сервер поднимается здесь, отдаёт себя по stdio и по http на случайном
порту петли (`serveMcpHttp`, сопоставление ответов — `mcpRequests` сервера) и пишет запись о себе;
уходит — убирает, если запись ещё его. Форма записи — `platform-file.ts` сервера, диск и сеть —
здесь.

## Правила

Своей модели карты у приложения нет: она в `abstract-server`, сюда приходит готовой. Появилась
логика, которую хочется положить рядом с адаптером, — значит она серверная и место ей в пакете.

Процессы плагинов — у того, кто поднял платформу карты. Разовые команды (`metric`, `object`,
`plugin check`) поднимают свои и гасят их на выходе; `mapward mcp` при живой платформе своих не
поднимает вовсе — решения [0013](../decisions/0013-metrics-store.md) и
[0014](../decisions/0014-client-server.md).

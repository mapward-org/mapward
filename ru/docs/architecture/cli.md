# CLI

Приложение: реализует порты сервера и делает с картой то же, что редактор, только из
терминала — поднимает MCP-сервер или выполняет серверную команду, например собирает метрику.
Решение [0014](../decisions/0014-client-server.md).

## Структура

Точка входа плюс реализации портов сервера: файлы, слежение, процессы оболочки, агент, время.
Клиента CLI не тянет — команда, печатающая метрику, ничего не рисует.

## Правила

Своей модели карты у приложения нет: она в `abstract-server`, сюда приходит готовой. Появилась
логика, которую хочется положить рядом с адаптером, — значит она серверная и место ей в пакете.

Свой стор у каждого, кто поднял сервер: у окна редактора свой, у CLI свой. Общего состояния
между ними нет — решение [0013](../decisions/0013-metrics-store.md).

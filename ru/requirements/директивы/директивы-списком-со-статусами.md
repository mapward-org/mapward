# Директивы видно списком, со статусом каждой

Директивы объекта открываются из меню в ряду с названием, отсортированные от новых к старым.
Статус считается сравнением текста директивы с копией, которую оставил прогон — решение `0002`:
копии нет — новая, копия другая — изменилась, совпадает — выполнена. Статусы помечены цветом.

Кнопок запуска у директивы нет — её выполняет агент из терминала объекта, решение `0017`.
Клик по самой директиве открывает её файл.

Сверху списка — создать директиву: расширение спрашивает, о чём она, делает из ответа имя файла
с датой и временем и открывает пустой файл на правку.

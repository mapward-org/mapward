# Сквозное правило задаётся один раз

`directives-workflow.prompt` в `_index.json` приклеивается к промпту любого этапа этого
объекта. Так задаётся то, что верно для всех прогонов, без переписывания каждого этапа.

Поле наследуется вместе с остальными, поэтому заданное на базовом прототипе действует на всю
карту.

## Сценарий

Хук есть — агент видит его в тексте этапа, а не отдельным сообщением: для него это один промпт.

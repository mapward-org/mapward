# Трейс сквозной через агента и MCP

Любой вход в платформу заводит трейс: кнопка экшона, строка списка, инструмент MCP,
`mapward action`, сбор метрики. Трейс едет вниз сам: вложенный вызов плагина и просьбы к платформе — в
трейсе вызова, откуда их сделали; процессам `shell` и `agent` — переменной `MAPWARD_TRACE`; в MCP —
заголовком `x-mapward-trace`. Плагин `agent` запускает Claude с конфигом MCP, где трейс стоит
заголовком. Вызов MCP без трейса заводит свой. Каждый вызов инструмента MCP — строка в
`mapward.log` с трейсом. Решение `0049`.

## Сценарий

Экшон запускает агента, агент через MCP зовёт плагин и запускает другой экшон. В логах всё это
лежит под трейсом первого экшона, и на экране его прогона видно, что сделал агент.

# Агент запускает экшон

`read_object` отдаёт экшоны объекта с адресом и полями формы, `run_action` запускает экшон с
данными формы — то же, что кнопка, и прогон виден человеку на экране прогонов. По умолчанию вызов
ждёт конца и отдаёт прогон целиком; с `wait: false` отдаёт номер, итог — `read_run`. Поля не
прошли — отказ с перечнем полей. Решение `0038`.

## Сценарий

Агент зовёт экшон без обязательного поля и получает отказ, где это поле названо. С полем — прогон
со статусом, шагами и логами, помеченный как запущенный агентом.

# Объект показывает, где ты находишься

Заголовок объекта — «название прототипа: название объекта», например «Пакет: core». Без
прототипа остаётся только имя объекта.

Над заголовком хлебные крошки по объектам с кнопкой назад. Текущий объект в крошках не
повторяется: он и так написан заголовком.

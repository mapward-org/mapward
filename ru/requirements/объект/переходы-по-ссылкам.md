# Ссылка ведёт туда, куда обещает схема

Ссылка на файл открывает файл в редакторе. Ссылка `mapward://` на объект карты открывает
объект в сайдбаре. Всё остальное — наружу, в браузер.

Рендерер решает это по схеме адреса, а не по настройке метрики — решение `0004`.

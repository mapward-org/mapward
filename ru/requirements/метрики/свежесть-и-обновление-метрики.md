# По метрике видно, когда её собирали и чем кончилось

Рядом с названием метрики — время с последнего обновления, если метрика с кэшем. Без кэша
показывать нечего: она собралась только что.

Кнопка обновить появляется при наведении, во время сбора крутится лоадер. После прогона
вместо лоадера точка: зелёная при успехе, красная при неудаче, по клику открываются логи.

## Сценарий

Кнопки не мельтешат: в спокойном сайдбаре видно только название, остальное появляется при
наведении на строку.

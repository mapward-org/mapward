# Требования лежат единым реестром

Требования всей системы лежат в одном месте — `ru/requirements`, папками по смыслу. За тем,
какой объект требование выполняет, отвечает поле `object` во фронтматтере, адресом по
решению `0005`. Требование без `object` — продуктовое, оно про систему целиком.

Это требование продуктовое: у него `object` не указан, и оно видно на корне карты, а не
у расширения.

## Сценарий

Объект показывает свой срез реестра: метрика фильтрует требования по его адресу. Корень
показывает всё, включая продуктовые.

Скрипт сверяет адреса с картой: если объект переименовали, требование становится сиротой,
и метрика «Битые адреса требований» показывает, какое именно.

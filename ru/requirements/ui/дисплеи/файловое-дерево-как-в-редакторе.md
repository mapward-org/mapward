# Файловое дерево выглядит как в редакторе

Дисплей `tree` рисует дерево так, как человек уже привык: папки первыми, имена по алфавиту без
учёта регистра, иконки по типу файла, шеврон у папок.

Клик по файлу открывает файл, клик по папке сворачивает и разворачивает её.

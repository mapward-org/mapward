# Экшон запускается со строки дисплея

Строка списка и узел дерева с полем `action` получают справа кнопку запуска, а клик по самой
строке по-прежнему ведёт по ссылке. Кнопка идёт тем же путём, что кнопка в шапке, с данными
формы из строки. Неизвестный экшон — ошибка строки, а не всей метрики. Компонент-дисплей получает
экшоны и запуск в пропсах. Решение `0038`.

## Сценарий

У упавшего теста в списке две возможности: открыть файл кликом по строке и перезапустить тест
кнопкой справа.

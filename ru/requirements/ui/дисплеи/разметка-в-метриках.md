# Текст в метрике показывается разметкой

Значения метрик бывают текстом — вывод проверки, объяснение расхождения, ответ агента, — и
одной длинной строкой они не читаются. Решение `0027`.

Дисплей `markdown` берёт ту же форму, что `text`: `{ text }`. Метрика переключается между ними
правкой `display.kind`, не трогая коллекторы.

Разбирается названное подмножество: заголовки, абзацы, списки маркированные и нумерованные с
вложенностью по отступу, цитаты, блоки кода, горизонтальная черта; в строке — код, ссылки,
жирный и курсив. Таблиц, картинок, сносок и html нет, вложенных выделений тоже: строка таблицы
покажется абзацем, и текст при этом не пропадёт.

`description` у элемента списка и узла дерева рисуется тем же разбором без блоков: там нужны
жирный, код и ссылки, чтобы проверка могла сказать, что именно разошлось.

Ссылка из разметки ведёт туда же, куда любая ссылка карты: `mapward://` в объект, прочее со
схемой наружу, остальное файлом — решение `0005`.

## Сценарий

Метрика-проверка возвращает отчёт абзацами и списком со ссылками на файлы. В сетке он виден
как текст с отступами; клик по ссылке открывает файл в редакторе, клик по `mapward://` уводит
на объект карты.

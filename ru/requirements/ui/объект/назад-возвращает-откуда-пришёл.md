# Назад возвращает туда, откуда пришёл

На объект приходят не только сверху: по ссылке из метрики, с карты детей, из разметки. Стрелка
«←» над заголовком возвращает на тот объект, с которого пришёл, «→» — обратно. К родителю ведут
крошки. Решение `0036`.

Шаг — переход на другой объект. Вкладка, мета-экран и метрика во всю ширину шагами не считаются,
но возвращаются вместе со своим шагом.

Когда идти некуда, стрелка гаснет, но стоит на месте. Объект, которого на карте больше нет,
стрелка перешагивает.

История своя у каждого таба и у каждой карты в сайдбаре и переживает перезагрузку окна: экран
возвращается тем же, и назад по истории тоже можно. Закрытый таб уносит свою историю с собой.

# Объект показывает, где ты находишься

Заголовок объекта — «название прототипа: название объекта», например «Пакет: core». Без
прототипа остаётся только имя объекта.

Над заголовком хлебные крошки по объектам, перед ними стрелки назад и вперёд по истории
переходов — [назад возвращает туда, откуда пришёл](назад-возвращает-откуда-пришёл.md). Текущий
объект в крошках не повторяется: он и так написан заголовком.

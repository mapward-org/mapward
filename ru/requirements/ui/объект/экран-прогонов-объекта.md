# Прогоны объекта видно на своём экране

Экран прогонов — третий вид объекта рядом с метриками и «об объекте»: виды переключаются
иконками в строке навигации. Это интерфейс к логам с фильтрами: по объекту и по плагину на
объекте. Слева прогоны объекта, свежие сверху, идущий обновляется живьём; справа выбранный:
конфиг после подстановок, данные формы, шаги с логом и выводом, «остановить». Прогон виден, пока
его трейс лежит в логе. «Все логи» карты и «по плагину все» — дополнительный вид для отладки, а
не основной. Решения `0038`, `0049`.

У метрики зелёной точки нет, только красная. Она открывает трейс сбора, если он ещё в логе; иначе
причина видна в значении метрики.

## Сценарий

Метрика покраснела — клик по точке открывает её последний трейс, где у упавшего шага виден лог.

Экшон запустил агента, тот через MCP позвал плагин — на экране прогонов экшона видно и ход агента,
и ход позванного плагина.

# Ссылка ведёт туда, куда обещает схема

Куда вести, решает схема адреса: `mapward://` открывает объект в сайдбаре, любая другая схема
уходит наружу, в браузер. Адрес без схемы — файл в проекте, он открывается в редакторе, и
буква диска схемой не считается: иначе на windows каждый путь уезжал бы в браузер.

Решает это рендерер по адресу, а не настройка метрики — решение `0005`.

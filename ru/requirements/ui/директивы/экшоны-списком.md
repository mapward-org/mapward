# Экшоны объекта видно списком

Экшоны показываются списком — разделом «Экшоны» на мета-экране объекта (решение `0024`), клик
открывает `config.json` экшона. У доставшегося от прототипа в строке сказано, чей он: лежит файл
там, и править его надо там же.

Мета-экран про устройство, поэтому экшон здесь открывают, а не запускают. Запускают его кнопкой
из шапки объекта и из сетки — решение `0038`.

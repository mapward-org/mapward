# Экшоны объекта видно списком

Экшоны показываются списком — разделом «Экшоны» на мета-экране объекта (решение `0024`), клик
открывает файл экшона. У доставшегося от прототипа в строке сказано, чей он: лежит файл там,
и править его надо там же.

Кнопкой запуска экшон не становится: он инструкция, которую подключает директива — решения
`0002` и `0010`.

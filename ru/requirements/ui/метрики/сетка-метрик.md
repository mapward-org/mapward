# Метрики раскладываются сеткой объекта

Раскладка берётся из `_index.json` объекта: `areas` называют метрики по клеткам, `style`
уезжает в контейнер как есть — решение `0003`. Метрика, не названная в `areas`, не
показывается и не собирается — решение `0029`; раскладки нет вовсе — показываются все метрики
объекта.

Сетка растёт по содержимому, а область метрик прокручивается целиком; шапка, директивы и
вкладки стоят на месте — решение `0033`. Код ничего не подставляет: высоты рядов, потолки и
растяжение на всё окно раскладка пишет обычным css в `style`. Содержимое, которое в отмеренный
ряд не влезло, прокручивается внутри своей клетки.

Раскладка словарём работает по ширине области метрик: ключ — условие `@container`, побеждает
последний подошедший; метрика, которой нет в сработавшем варианте, скрыта.

Сетка раскладывает метрики открытой вкладки, и раскладку берёт у неё, если вкладка задала свою —
требование `вкладки-метрик`. Вкладок нет — раскладываются все метрики объекта, как и раньше.

Метрику можно свернуть тогглером у названия. Свёрнутость помнит редактор в своём состоянии —
это удобство человека, репозиторий её не видит.

Метрика может прийти свёрнутой: `collapsed` в конфиге. Свёрнутое руками перекрывает
умолчание — решение `0010`.

# Прогоны экшонов и метрик лежат локально

Прогон — откуда запущен, когда, с какими данными, шаги с логом и выводом, итог. Своего
хранилища у прогонов нет: начало и конец трейса ложатся строками в `.mapward/logs/mapward.log`,
ход вызовов — в логи плагинов, и прогон собирается из строк своего трейса. Живёт он, пока его
строки в логе: 10 МБ на файл и одна предыдущая копия. В git логи не попадают: в `.mapward/` лежит
`.gitignore` со звёздочкой. `.mapward` объектом карты не считается. Решения `0038`, `0049`.

Прогоны одного экшона идут параллельно, у каждого свой номер — номер трейса — и своя остановка.
Таймаут снимает прогон неудачей с причиной. Трейс без строки конца после перезапуска окна
показывается прерванным.

## Сценарий

Экшон запускают дважды с разными данными — идут два прогона, один останавливают, второй доходит
до конца. После перезапуска окна оба видны в истории объекта, собранные из лога.

Упавший шаг останавливает прогон: следующие шаги не запускаются, у прогона причина неудачи.

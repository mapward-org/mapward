# Прогоны экшонов и метрик лежат локально

Прогон — откуда запущен, когда, с какими данными, шаги с логом и выводом, итог. Прогоны экшонов и
метрик пишутся в `.mapward/runs/` корня карты, по двадцать последних на экшон или метрику, и в
git не попадают: в `.mapward/` лежит `.gitignore` со звёздочкой. `.mapward` объектом карты не
считается. Решение `0038`.

Прогоны одного экшона идут параллельно, у каждого свой номер и своя остановка. Таймаут снимает
прогон неудачей с причиной. Прогон, шедший во время перезапуска окна, возвращается остановленным.

## Сценарий

Экшон запускают дважды с разными данными — идут два прогона, один останавливают, второй доходит
до конца. После перезапуска окна оба видны в истории объекта.

Упавший шаг останавливает прогон: следующие шаги не запускаются, у прогона причина неудачи.

# Экшон — папка с конфигом, как метрика

Экшон лежит в `_actions/<ключ>/config.json`: шаги по порядку (`script`, `prompt`), поля формы,
подтверждение, таймаут и метрики, которые пересобрать после успеха. Markdown в `_actions/` не
читается — инструкция для агента это дока, а не экшон. Решение `0038`.

Наследуется экшон так же, как метрика: по прототипу и через `extends` на общий. Свой с тем же
ключом перекрывает прототипов, поля формы сливаются по имени, подстановки разрешаются по объекту,
на котором экшон нажали.

## Сценарий

У прототипа «Пакет» заведён экшон — каждый пакет видит его своим адресом и с прототипом как
владельцем, а подстановка в его промпте берёт имя пакета, а не прототипа.

Экшон пакета с одной строкой `extends` получает шаги и поля общего экшона и добавляет своё поле,
не теряя остальных.

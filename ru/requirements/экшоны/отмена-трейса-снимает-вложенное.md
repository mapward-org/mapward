# Отмена трейса снимает вложенное

Любой идущий вызов и трейс можно отменить. Отмена трейса снимает все его идущие вызовы, вложенные
тоже, и трейсы, заведённые внутри него: экшон, который агент экшона запустил через MCP. Обёртки
для отмены нет — это отписка; плагин видит её по `ctx.signal` и гасит своё, `shell` и `agent`
снимают процесс вместе с детьми. Решение `0049`.

## Сценарий

Экшон запустил агента, агент через MCP запустил второй экшон со скриптом. Человек останавливает
первый — останавливаются агент, второй экшон и его скрипт, оба прогона кончаются «остановлен».

# Вебвью и хост говорят типизированным rpc

Вебвью не умеет ни файлов, ни терминалов, хост не умеет рисовать. Между ними мост поверх
`postMessage`: вызовы и подписки типизированы с обеих сторон из одного описания.

Описание — контракт: обе стороны знают из него одно и то же, а транспорт снаружи и заменим
(`postMessage` в редакторе, http или stdio для CLI и MCP). При переезде по решению `0014`
контракт живёт в `core`, а не в приложении.

## Сценарий

Параметры вызова приходят из вебвью, поэтому проверяются схемой на входе в хост. Результат
идёт из нашего же кода и типизируется на клиенте, без второй проверки.

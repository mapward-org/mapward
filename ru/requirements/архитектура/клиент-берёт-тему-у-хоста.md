# Внешний вид приходит от хоста, а не зашит в клиент

Клиент рисует на React и tailwind, а цвета, шрифты и иконки получает от хоста через порт:
набор переменных объявлен контрактом клиента, заполняет их приложение — решение `0014`.

Сейчас интерфейс насквозь редакторный: два десятка переменных `--vscode-*` и шрифт codicon.
Пока это так, клиент абстрактен только по названию.

## Сценарий

В редакторе карта выглядит нативно — значения приходят из темы vscode. Тот же клиент,
запущенный в браузере, получает значения оттуда и рисуется без единой правки в коде клиента.

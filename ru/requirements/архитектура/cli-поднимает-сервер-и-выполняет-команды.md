# С картой можно работать без редактора

CLI реализует порты сервера и делает две вещи: поднимает MCP-сервер и выполняет серверную
команду — например собирает метрику и печатает результат (`0014`, `0009`).

Это же и доказательство переезда: если метрика собирается из терминала, значит модель
действительно не зависит от редактора.

## Сценарий

Свой стор у каждого, кто поднял сервер: у окна редактора свой, у CLI свой. Общего состояния
между ними нет — расходятся они ровно настолько, насколько разошлись прогоны.

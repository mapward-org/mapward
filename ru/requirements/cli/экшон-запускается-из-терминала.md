# Экшон запускается из терминала

`mapward action <адрес> [карта] [--input имя=значение]...` запускает экшон тем же прогоном, что
кнопка: шаги печатаются по мере того, как кончаются, а код выхода говорит, чем кончился прогон.
Ошибки полей печатаются по полю, прогона тогда нет. Решение `0038`.

## Сценарий

Экшон из CI запускают с `--input level=minor`: вывод шагов идёт в лог сборки, неудача роняет шаг
ненулевым кодом.

# Две пустоты лечатся по-разному

Карты может не быть по двум причинам, и они требуют разного — решение `0008`.

## Сценарий

Папка открыта, конфига в ней нет — кнопка создать `mapward.json`: место известно, остаётся
записать.

Папка не открыта вовсе — кнопка найти: диалог выбора папки, дальше редактор открывает её как
воркспейс. Кнопки создать здесь нет: файл некуда класть, а выбирать сам `mapward.json` вредно —
карта окажется вне воркспейса.

# План первой версии

Поведение — `ru/docs/requirements.md`, модель — решения `0002`–`0007`, устройство кода —
`Architecture.md`. Пункты идут так, чтобы каждый давал проверяемый результат, а не слой
без применения.

## 1. База расширения

- [x] манифест: `engines.vscode`, `activationEvents`, `contributes` — контейнер в activity
      bar и вью внутри него
- [x] две сборки: `extension` (cjs, node, `vscode` внешний) и `webview` (esm, браузер)
- [x] tailwind в сборке вебвью
- [x] активация: провайдер вью, html вебвью с csp и nonce
- [x] мост `postMessage`: типы сообщений в `kernel`, транспорт в `shared` — переедет
      в `adapters` фичи, когда появится первая фича
- [x] вебвью рисует заглушку и отвечает на пинг — цепочка host ↔ webview проверена
- [x] `.vscode/launch.json`, README с тем, как запускать и разрабатывать

## 2. Чтение карты

- [x] типизированный rpc поверх postMessage: контракт в `kernel`, вызовы и подписки
      в `shared/bridge`, валидация параметров typebox
- [x] `mapward.json`: поиск снизу вверх от каждой папки воркспейса, `maps` со своими
      `mapUrl` и `baseUrl`, дедуп по пути карты
- [x] одна карта — сразу объект, несколько — аккордеон
- [x] папка открыта без конфига — кнопка создать; папки нет — кнопка найти
- [x] подписка на `mapward.json` и на смену папок воркспейса
- [x] обход карты: объекты, группы, метрики, директивы, экшоны
- [x] `extends` объектов и метрик, мердж по `0003`
- [x] адресация `mapward://` — путь, значение, `~`, `@`
- [x] подстановки `${{ }}` после резолва extends

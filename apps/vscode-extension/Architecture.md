# Архитектура расширения

## Структура

```
src/
  apps/            точки входа. Не реализуют бизнес-функции: связывают фичи и запускают
    extension/     рантайм расширения — vscode api, файлы, терминалы
    webview/       рантайм вебвью — react, отрисовка
  features/        крупные независимые единицы функций
    feature/
      index.extension.ts   public api для расширения: всё явно, без `*` в импортах
      index.webview.ts     то же самое для вебвью
      compose/     точки входа в модуль — компоненты, хуки, функции. Логики нет,
                   композирует model, ui, adapters, pure-model. Чистых реакт-хуков
                   и дивов здесь тоже нет
      _sub-module/ подмодуль, устроен так же
      model/       управление внутренним состоянием модуля — тем, которым он владеет
      adapters/    адаптеры к внешнему состоянию, которым модуль не владеет
      ui/          компоненты: вёрстка и, самое большее, состояние отображения
      pure-model/  типы и чистые функции
  kernel/          связующий слой фич: только типы, чистые функции, порты, контексты
  shared/          переиспользуемые модули без бизнес-информации. Чётких правил нет,
                   но декомпозированы по low coupling / high cohesion
```

## Правило импортов приложения

```
apps -> features (feature|feature) -> kernel -> shared
```

Импорты через уровень разрешены.

## Правило импортов фичи

```
compose -> (model|adapters|ui) -> pure-model
```

**`model`, `adapters` и `ui` не импортируют друг друга** — связь только через `compose`.

Подмодули могут использовать `pure-model` родителя. Родитель обращается к дочернему
модулю только внутри `compose`.

```
compose -> _submodule -> pure-model
```

## Изоморфность

Расширение живёт в двух рантаймах: extension host знает `vscode`, файлы и терминалы,
вебвью умеет только рисовать. Инкапсулируем по фичам, а не по рантайму: фича — это срез
функции целиком, и код внутри неё изоморфный.

Зависимости от рантайма живут **только в адаптерах**. Так удобно контролировать связность
и потом подменять реализацию.

`model` не имеет связей внутри себя, поэтому разные рантаймы через разные `compose`
тянут разные `model`. Два бандла получают по своей копии — это не рассинхрон, а
разделение владения: host владеет данными, вебвью владеет видом.

Наружу фича смотрит двумя файлами — `index.extension.ts` и `index.webview.ts`. Что
каждый рантайм видит от фичи, решает её автор, а не сборщик.

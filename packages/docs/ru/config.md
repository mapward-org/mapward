# Настройка и поиск карты

Карту надо сначала найти. Инструмент запускается из терминала, из расширения, из CI — cwd
везде разный, и опору в него класть нельзя. Опора одна: файл настройки в проекте.

```json
{
  "maps": [
    { "mapUrl": "ru/map", "baseUrl": "." }
  ]
}
```

`mapUrl` — директория карты, обязателен. `baseUrl` — корень проекта этой карты, от него
резолвится [`@`](addressing.md), умолчание `.`.

Оба пути считаются **от папки самого `mapward.json`**: это единственное место, известное
точно ещё до того, как что-то прочитано. Отдельным параметром `baseUrl` нужен, когда конфиг
лежит не в корне — например в подпапке монорепы, а код выше.

Здесь же настройки MCP-сервера — его адрес и запреты на сеть, см. [MCP](mcp.md).

## Настройки рантайма

В том же файле, рядом с `maps`:

```json
{
  "maps": [{ "mapUrl": "ru/map" }],
  "mcpPort": 47318
}
```

`mcpPort` — постоянный порт MCP-сервера в редакторе, хост всегда `127.0.0.1`. Без него порт
случайный, и терминалы карты перезагрузку окна не переживают — см. [MCP](mcp.md). Занят (тот же
проект открыт во втором окне) — редактор предупреждает и берёт случайный. Порт в конфигах один
на окно: разные — ошибка настройки, берётся первый. На том же порту редактор держит и мост
клиента по http (`/bridge`) — им рисует метрики встроенный плагин `screenshot`.

Адрес живой платформы — не настройка: его пишет сама платформа в `<карта>/.mapward/platform.json`
и убирает, когда останавливается; `mapward mcp` находит её там (см. [MCP](mcp.md#одна-платформа-на-карту)).
`.mapward` — локальное, вне git.

Свежести, параллельности и дебаунса метрик здесь больше нет: метрика — компонент, и когда звать
плагин, решает он сам (см. [метрики](metrics.md)). Старые поля в `mapward.json` не мешают — они
просто не читаются.

## Почему список карт

Карт в проекте бывает несколько: у монорепы своя на подсистему, у документации на двух
языках — своя на язык. У каждой свой `baseUrl`, поэтому и `@` у каждой свой.

## Поиск

От текущей директории вверх до корня файловой системы, первый найденный выигрывает. Так же
ищут свои конфиги git и пакетные менеджеры — привычка уже есть.

Конфига нет — карты нет: CLI останавливается и говорит, где искал.

## В редакторе

У редактора cwd нет вовсе: воркспейс — это ноль, одна или несколько папок, открытых
одновременно. Поэтому поиск идёт от каждого корня вверх, а итог — плоский список карт со всех
корней.

Дедуп по абсолютному пути **карты**, а не конфига. В монорепе две открытые подпапки
поднимутся к одному `mapward.json`, но и два разных конфига могут указать на одну карту, и
такой дубль дедупом по конфигу не поймать.

Одна карта — сразу её корневой объект, как будто выбора нет. Несколько — аккордеон: секция
на карту, разворачивается как корни воркспейса в проводнике.
Свёрнутая карта не сбрасывается: раскрытые узлы, выбранный объект и прокрутка ждут, пока её
развернут. Какие карты свёрнуты, помнится и после перезагрузки окна — свёрнутая к тому моменту
карта не грузится, пока её не откроют.

## Когда карты нет

Две пустоты, и лечатся они по-разному.

**Папка не открыта вообще** — кнопка «найти»: диалог выбора папки, дальше редактор открывает
её как воркспейс. Кнопки «создать» здесь нет: создавать файл некуда, а предлагать выбрать сам
`mapward.json` вредно — карта окажется вне воркспейса, и ссылки на файлы поведут непонятно куда.

**Папка открыта, конфига в ней нет** — кнопка «создать `mapward.json`». Место известно,
остаётся записать.
